# 第二章 相关理论基础

本章建立全文的理论与工程基础。2.1 节介绍 LLM 代码生成与 OpenEvolve 进化框架的机制，
重点是质量多样性搜索；2.2 节综述定点算术误差分析的工具与结论；2.3 节引入等价饱和
结构作为"算法族导航"的形式化背景；2.4 节给出本文的核心形式化对象——数学规范与 RTL
实现之间的 ε-等价关系，以及在其上定义的评估 oracle 层级。第四章的证书引擎与第五章
的实验方案均建立在本章定义之上。

## 2.1 LLM 代码生成与进化式框架

### 2.1.1 LLM 作为变异算子

设代码空间为 $\mathcal{P}$（所有合法程序文本），LLM $\mathcal{M}$ 是一个条件分布
$\mathcal{M}(\cdot \mid c)$，其中上下文 $c$ 包含任务规范、父代程序与评估反馈。在
"进化式代码生成"范式（AlphaEvolve，2025）中，$\mathcal{M}$ 不直接一次性产出最终程序，
而是作为**变异算子**在搜索循环中反复调用：父代集合 $P_t$ 经选择、变异、评估后形成
$P_{t+1}$。与传统进化算法的区别在于变异算子不是句法扰动，而是由一个在超大语料上
预训练的模型执行——它能做出保持语义的局部修改（如把移位位数加一、把表项从 64 扩到
128），也能提出结构性重写（如把查表改为迭代）。

这一范式的效率由三个因素决定：(a) 变异算子的有效性（LLM 产出可解析、可综合候选的
比率）；(b) 评估器的信息量（反馈给 LLM 的指标能否引导其走向更优区域）；(c) 搜索
空间的组织方式（自由文本空间 vs 受约束空间）。本文第五章的实验设计正是围绕
(b)、(c) 两个因素展开的受控对比。

### 2.1.2 OpenEvolve：MAP-Elites 与岛屿模型

OpenEvolve 是 AlphaEvolve 的开源复现，本文以其为实验基座。其核心机制：

**MAP-Elites 质量多样性网格**。将程序映射到由行为描述子（behavior descriptors）划分
的多维网格，每个网格单元保留其"精英"。本文将描述子设为（精度 $p$，面积 $a$，吞吐
$t$），网格分辨率 $(8, 8, 4)$。设任务归一化常数 $\pi_{\max}, A_{\rm ref}$，单元坐标为
\[ i_p = \lfloor 8 \cdot \min(p/\pi_{\max}, 1) \rfloor,\quad
   i_a = \lfloor 8 \cdot \min(a/A_{\rm ref}, 1) \rfloor,\quad
   i_t = \lfloor 4 \cdot t \rfloor. \]
每个单元保留 combined_score 最高者。与单目标进化不同，MAP-Elites 的最终产物是覆盖
整个精度-面积折中面的**Pareto 前沿**，而非单个最优点——这与通信算子"精度可谈判"的
语义天然匹配。

**岛屿模型与迁移**。种群分为若干岛屿独立进化，周期性迁移防止早熟收敛。本文实验统一
使用 2 岛屿、精英比例 0.2、探索/利用比 0.3/0.7 的默认配置。

**级联评估**。评估器分两级：L1 冒烟（256 样本快速仿真，分数封顶 0.49 防止"超时幻影
最优"）与 L2 全量评估（65536 样本仿真 + Yosys 综合）。级联阈值 0.2（约 12 dB）以下的
个体不进入 L2 但保留在网格最差单元中——保留失败个体作为父代材料形成"修复环路"，
这一机制在数值硬件生成中不可或缺（本文实测 LLM 产出的可综合比率在 49%~98% 之间
波动，取决于任务与迭代阶段）。

**混合变异模式**。本文在框架中新增 per-iteration 变异通道采样：每次迭代以概率
$p_{\rm rw}$ 走"全重写"通道（LLM 重写整个进化块），否则走"diff"通道（LLM 给出
SEARCH/REPLACE 块）。预实验（附录 A）确认混合模式 $p_{\rm rw}=0.5$ 优于纯 diff
（超体积 0.458 vs 0.355）——纯 diff 通道在 52 次迭代内精度零增长，其结构性短板
（文本局部变异难以跨越算法类边界）是第五章"算法类地板"现象的微观机制。

### 2.1.3 LLM 后端

所有实验使用 DeepSeek `deepseek-flash`（思维链开启，max_tokens = 32768）。思维链
token 与正文共享输出预算：本文在预实验中发现 8192 预算会被思维链完全耗尽导致正文
为空（finish_reason=length），这是接入推理型模型时的常见工程陷阱。论文如实声明：
所有进化调用由该单一后端完成，方法与后端无关（框架只依赖 OpenAI 兼容接口）。

## 2.2 定点算术的误差分析

### 2.2.1 量化误差模型

设量化器 $Q_s(\cdot)$ 把整数 $v$ 就近舍入到 $2^s$ 的倍数（丢 $s$ 个低位），误差
$e = Q_s(v) - v$ 满足 $|e| \le 2^{s-1}$（就近舍入）或 $e \in (-2^s, 0]$（截断）。
传统分析在"误差近似均匀分布于一个 LSB"的假设下取 $E[e^2] = q^2/12$（$q = 2^s$）。
该假设对位流经统计复用的信号是良近似的，但它是一个**近似**：论文第四章将展示，对
整数域数据通路，误差的精确分布可以从输入分布**解析地**导出，均匀假设的偏差在低字长
端不可忽略。

对线性数据通路（乘积的线性组合），各量化器的误差以线性系数传播：输出误差
$e_y = \sum_i g_i e_i$，最坏情况界为 $|e_y| \le \sum_i |g_i| \cdot \max|e_i|$
（区间算术口径，对全体输入成立），均方口径为
$E[e_y^2] = \sum_i g_i^2 \sigma_i^2 + \text{交叉项}$。本文的证书引擎同时输出这两个
口径：**最坏界**（sound，可作为设计保证）与**均值**（用于排序，在满足引理条件时精确
等于总体值）。

### 2.2.2 从 SQNR 到通信系统指标

通信算子的精度指标最终由系统级 BER/EVM 决定。对加性误差模型，量化噪声在解调器判决
点的统计由整个接收链的传递特性决定。线性系统的最坏峰值增益可由最坏情况增益计算
（worst-case peak gain, WCPG）方法得到，FloPoCo 的定点 FIR 生成器即以 WCPG 自动
推导无溢出的内部位宽。第五章的 E4 实验将展示：以端到端 BER 约束为目标（解析界而非
蒙特卡罗）得到的位宽分配，可以比以 SQNR 代理为目标更省面积——这说明"SQNR 不是
正确的目标函数"这一论断在通信语境下可以定量成立。

### 2.2.3 仿射算术与区间算术

区间算术（interval arithmetic）把每个中间量的取值范围表示为区间 $[l, u]$，运算后
区间按最坏情况扩张；仿射算术（affine arithmetic）进一步把量表示为中心值加噪声项
线性组合 $v = v_0 + \sum_k \epsilon_k \sigma_k$，使相关误差项部分相消，界更紧。
两者的代价随表达式规模增长，且对含条件分支或非线性强的结构（除法、迭代）会显著
高估。本文证书引擎在**数据通路为线性的家族**（复数乘法）上使用闭式区间传播，在
**解析可导的家族**（atan2、sin 的插值误差）上使用函数导数界，避免了一般性的
区间爆炸问题——这是"族特化证书"设计（§4.3）相对通用符号执行的关键取舍。

## 2.3 等价饱和与实现空间的结构

e-graph 是一种紧凑表示大量等价表达式的数据结构：等价关系经重写规则闭包后，所有
可达的等价形式共存于同一图中，提取（extraction）阶段按代价函数选出最优代表。
等价饱和（equality saturation）技术已在 RTL 数据通路优化中落地：ROVER（2024）以
带验证的 e-graph 重写 RTL，ASPEN（MLCAD 2025）用 LLM 自动生成重写规则。

本文第五章把这一思想推广到两个新维度：

1. **定量的等价**：e-graph 的等价类从"精确相等"推广为"$\varepsilon$-等价"——两个
   实现属于同一类，当且仅当它们与同一数学规范的偏差都被同一误差预算 $\varepsilon$
   覆盖。类内变换（如 Karatsuba 分解）保持精度不变、只移动成本；类间变换（如最近邻
   →线性插值）改变精度-成本折中，需要重新求解证书；
2. **算法族的图导航**：传统"算法目录"（CORDIC / 查表 / 多项式各为离散条目）被一张
   参数化的实现图取代：图的节点是（结构，参数）配置，边是"保精度的结构重写"或
   "变精度的参数调整"，导航即在图上以证书为代价函数做搜索。

## 2.4 核心形式化对象

### 2.4.1 ε-等价

**定义 2.1（ε-等价）**。设数学规范 $f: \mathcal{X} \to \mathbb{R}^m$（$\mathcal{X}$
为任务规范锁定的输入域及分布 $\mu$），实现 $g: \mathcal{X} \to \mathbb{Z}^m$ 为其
定点输出。称 $g$ 是 $f$ 的 $\varepsilon$-实现，若
\[ \mathbb{E}_{x\sim\mu}\big[\|f(x) - g(x)\|_\infty^2\big] \le \varepsilon^2
   \quad\text{且}\quad
   \sup_{x\in\mathcal{X}} \|f(x)-g(x)\|_\infty \le B(\varepsilon), \]
其中第一式为分布平均口径（由评估 oracle L2 计算），第二式为最坏情况口径（由 L3
证书给出）。两个实现 $g_1, g_2$ 称为同类的，若它们对同一 $f$ 的证书可交换（结构
重写不改变两者的界）。

**说明**。仿真验证只能对有限样本集 $S \subset \mathcal{X}$ 断言
$\frac{1}{|S|}\sum_{x\in S}\|f(x)-g(x)\|^2$，且该统计量随 $S$ 随机变化；ε-等价把
"正确性"从"有限样本上误差小"升级为"分布平均误差受控 + 最坏误差受控"的双重断言，
其可检验性由下述 oracle 层级保证。

### 2.4.2 评估 oracle 层级

**定义 2.2（评估 oracle）**。给定规范 $f$、分布 $\mu$ 与实现 $g$，评估 oracle 是
一个（确定性或随机的）过程，返回标量适应度
$F(g) = 10\log_{10}\frac{E_\mu[f^2]}{E_\mu[(f-g)^2]}$（SQNR 口径）。本文区分三级：

| 层级 | 机制 | 确定性 | 误差性质 | 每次代价 |
|---|---|---|---|---|
| L1 采样 | fresh-seed 蒙特卡罗，$|S|=2^{16}$ | ✗（随机变量） | $\text{std} \propto \kappa/\sqrt{|S|}$（$\kappa$ 为误差峰度） | 仿真 ~20 s |
| L2 确定性 | 固定种子 Sobol 格点 / 全枚举上的精确整数域仿真 | ✓（重评逐位一致） | 格点收敛误差（平滑被积函数下快速收敛） | 模型仿真 ~1 s |
| L3 声明性 | 区间/导数闭式最坏界 | ✓ | sound 上界（可能悲观） | 闭式 ~0 s |

**命题 2.1**。L2 与 L3 在满足下列条件时分别精确/sound：(a) L2 的仿真模型与 RTL 在
逐位语义上等价（第四章以逐点对拍验证）；(b) L3 的每个误差项是对应物理误差源（操作
数量化、舍入、逼近）的正确上界且各项以线性方式组合。

### 2.4.3 适应度噪声的病态性度量

对随机 oracle L1，定义估计的相对标准差 $\rho = \mathrm{std}[\hat{F}]/E[\hat{F}]$。
对平滑误差分布（量化噪声近似白），$\kappa$ 接近 3（高斯），$|S| = 2^{16}$ 时
$\rho \sim 0.6\%$（约 0.05 dB）——采样适应度可靠。但当误差分布重尾（少数输入贡献
绝大部分误差功率，LLR 族是典型），$\kappa \to \infty$，任何有限样本估计都不稳定。
第五章 E2 实验以实测数据量化了这两种情形，并说明其对进化搜索的不同影响。
