# 第四章 证书化评估体系

本章建立全文的核心方法：以确定性证书取代采样评估。4.1 节给出评估 oracle 层级的
工程化定义；4.2 节证明模分解引理——锚点任务（复数乘法）的总体均值 SQNR 可以零
采样、零积分误差地精确计算；4.3 节给出四个算子族的证书模型设计；4.4 节以逐位对拍
完成"模型-RTL"验证链；4.5 节报告实验中发现的重尾病态现象及其方法学含义。

## 4.1 评估 oracle 的三级层级

第二章定义 2.2 区分了三级评估 oracle。本节将其落实到 CommDSP-Bench 的工程语境：
适应度 $F(g)$ 的分子 $E_\mu[f^2]$（信号功率）与分母 $E_\mu[(f-g)^2]$（误差功率）
如何在每一层计算，以及各层的适用边界。

**L1 采样层（现行做法）**。OpenEvolve 原生评估器对每次评估以新鲜随机种子生成
$|S| = 2^{16}$ 个激励，golden 现算。其优点是防背题（P4）且实现简单；缺点是适应度
是随机变量——同一设计两次评估的分数不同，进化过程实际在优化
$E[\hat{F}] + \text{噪声}$，且存在被"样本侥幸"误导的风险。3.4 节的审计与 4.5 节的
实验将说明：对平滑误差分布该噪声约 0.03 dB（无害），对重尾分布可达两位数 dB
（致命）。

**L2 确定性层**。以固定种子的 Sobol 序列（scrambled，seed 锁定）替代随机采样，
并在**整数域精确仿真模型**上计算输出——模型复刻 RTL 的每一个舍入/截断位操作，
因此模型输出与 RTL 输出逐位一致（4.4 节验证）。对小输入空间任务（一维 16 位角度码）
直接全枚举 $2^{16}$ 个输入，此时 L2 退化为**精确总体值**，零积分误差。L2 的两个
关键性质：(a) **确定性**——同一候选重评分数逐位一致，适应度不再是随机变量；
(b) **无仿真依赖**——模型以 numpy 整数运算执行，单次评估 ~1 s 量级，比 iverilog
全量仿真快一个数量级以上。

**L3 声明性层**。对每个物理误差源给出解析上界（操作数量化界、逼近误差的导数界、
表系数舍入界），以线性组合成对**全体输入**成立的误差上界
$B$，输出最坏情况 SQNR 下界 $10\log_{10}(E[f^2]/B^2)$。L3 是 sound 的设计保证，
但通常悲观（各误差源同相取最坏的概率极低）；其角色是安全证书而非排序适应度。

**层级组合**。证书适应度 = L2 均值（排序用）+ L3 最坏界（安全用），两者都是输入
的确定性函数。与之配套的原则是**最终判定回归采样**：所有搜索得到的前沿个体，在
论文主表中统一用 L1 协议（采样评估）重判——证书负责"搜索中的可靠引导"，采样负责
"报告时的统一口径"，两者各司其职（第五章 5.3 节）。

## 4.2 模分解引理：锚点任务的精确误差矩

复数乘法 $y = (a+jb)(c+jd)$ 的输入为 16 位补码整数（Q1.15），数据通路先精确计算
乘积与加减（整数域无误差），最后对输出丢 $s$ 位定点化。误差
$e = Q_s(v) - v$（$v = ac - bd$ 或 $ad + bc$）只依赖残差 $r = v \bmod 2^s$。因此
总体均方误差为
\[ E[e^2] = \sum_{r=0}^{2^s-1} P(r)\,\varphi(r)^2, \]
其中 $\varphi(r) = Q_s(v)-v$ 在残差类上取值（就近舍入 half-up：
$\varphi(r) = -r\ (r<2^{s-1})$；$= 2^s - r\ (r>2^{s-1})$；$= 2^{s-1}$（平局向上）；
截断：$\varphi(r) = -r$）。全部难度集中在残差分布 $P(r) = P(v \bmod 2^s)$ 的精确
求解——$v$ 是两个独立乘积之差，其分布支撑在 $2^{32}$ 个整数上，直接枚举不可行。

**引理 4.1（残差分布的赋值分解）**。设 $a, c$ 独立均匀分布于连续 $2^n$ 个整数
（区间起点为 $2^{n-1}$ 的倍数），$A = ac$。当 $s \le n-1$ 时，
$(a \bmod 2^s)$ 均匀分布于 $\mathbb{Z}/2^s$，且由环同态
$ac \bmod 2^s = ((a \bmod 2^s)(c \bmod 2^s)) \bmod 2^s$，残差分布为

\[ P(A \bmod 2^s = r) \;=\; \sum_{j,k \ge 0} p_j\, p_k\,
   \frac{\mathbf{1}[\nu(r) = j+k] + \mathbf{1}[j+k \ge s,\ r = 0]}{2^{s-(j+k)-1}}, \]

其中 $\nu(\cdot)$ 为 2-adic 赋值，$p_j = P(\nu(a) = j) = 2^{-(j+1)}$（$j < n$）。
直观解释：乘积的低 $j+k$ 位为 0，其余位由奇数残差在乘法群上的均匀性给出。

*证明要点*。(1) 区间起点 $-2^{n-1}$ 是 $2^s$ 的倍数（$s \le n-1$）且区间长度
$2^n$ 被 $2^s$ 整除，故 $a \bmod 2^s$ 均匀；(2) 乘以固定奇数是
$\mathbb{Z}/2^m$ 上的双射且保持奇性，故给定 $\nu(a)=j,\ \nu(c)=k$ 时，
$A \bmod 2^s = 2^{j+k}\cdot o$，$o$ 为 $\bmod\ 2^{s-j-k}$ 上的均匀奇残差，且无
回绕（$o < 2^{m}$）；(3) 对 $j+k \ge s$，$A \equiv 0 \pmod{2^s}$。∎

**引理 4.2（圆卷积合成）**。$v = A - B$（$A, B$ 独立同分布）的残差分布是
$P_A$ 的圆卷积 $P_A * P_A^{(-)}$；Karatsuba 结构下
$im = P_1 - A - B$（$P_1 = (a+b)(c+d)$，$(a+b)$ 为 $2^{n+1}$ 个连续整数）对应
三重圆卷积。注意 $\varphi(A-B) \ne \varphi(A) - \varphi(B)$——模环上的回绕使得
"先分别量化再相减"与"先相减再量化"不是同一函数；本文初版实现即因忽略回绕产生
恰 3.01 dB 的系统性偏差，后被圆卷积公式纠正——这一教训说明精确矩必须对**整个
数据通路的量化点**建模，而非对逐量化器误差做独立性近似。

**定理 4.1**。在引理 4.1/4.2 条件下，$E[e^2]$ 可在 $O(2^s \log 2^s)$ 时间内
**精确**计算（FFT 圆卷积），从而锚点任务的总体均值 SQNR 可零采样、零积分误差
地获得。数值验证（表 4.1）：引理精确值与 $2^{16}$ 点 Sobol 积分的偏差 ≤ 0.02 dB，
且 Sobol 估计随点数收敛于引理值。

**适用边界**。$s \le n - 1$ 是引理前提（对 16 位输入即 $s \le 15$，对应输出丢位
不超过 15 位）；操作数截断（先截操作数再乘）破坏残差结构，须回退到 Sobol 积分。
两层机制在引擎中共存：引理路径作为"精确层"，Sobol 路径覆盖全空间——两者的
一致性本身构成交叉验证。

## 4.3 四族证书模型

各族的证书模型按"结构可解析度"分为四类，构成一个由精确到近似的谱系。所有模型
共享同一接口：`cert(params) → {precision (L2), precision_wc (L3), throughput
(结构解析)}`，Verilog 由模板从同一参数生成，保证模型与 RTL 的一一对应。

### 4.3.1 复数乘法（精确层 + 闭式界）
参数空间：操作数截断 $s_o \in [0,10]$、输出丢位 $s_d \in [0,8]$、舍入模式、
Karatsuba 结构。$s_o = 0$ 时引理给出精确矩；$s_o > 0$ 时（截断破坏残差结构）
用 Sobol 格点。一个关键的代数事实：**Karatsuba 重组
$im = (a_h{+}b_h)(c_h{+}d_h) - a_h c_h - b_h d_h$ 在整数域精确成立**——结构选择
不改变精度，只改变面积（3 个窄乘法器 vs 4 个）。这使"结构重写保精度"（ε-等价
类的类内边）在锚点任务上字面成立。L3 界由操作数量化界 $|e_o| \le 2^{s_o-1}$
传播：$|e_{\rm prod}| \le |e_a||c| + |a_h 2^{s_o}||e_c| + |e_a e_c|$，再加各输出
丢位界。

### 4.3.2 正余弦发生器（全枚举层）
一维输入（16 位角度码）使 $2^{16}$ 全枚举可行：L2 即为**精确**总体值。
模型逐位复刻四分之一波折叠、段索引、表值（$T_k = \mathrm{round}(\sin(2\pi k/N)
\cdot 2^{15})$）与线性/二次插值的每一个位操作（含"加丢位场 MSB"的就近舍入技巧）。
CORDIC 模式复刻 19/18 位寄存器宽度的逐级舍入与回绕。L3 界：插值误差
$|e| \le h^2\max|f''|/8$（线性，$\max|\sin''| = 1$）、$h^3\max|f'''|/24$（二次）、
$hb/2$（最近邻）；CORDIC 残余角 $\le \arctan 2^{-(n-1)}$ 加每级舍入项。

### 4.3.3 复数辐角 atan2（确定性积分层）
二维输入空间（$2^{32}$ 格点）不可枚举。模型复刻"八分折叠 → 截断除法
$r = \lfloor y \cdot 2^p / x \rfloor$ → 表查询/线性插值 → 象限重构"的整数域
位操作；L2 用 $2^{20}$ 点固定 Sobol 格点积分。L3 界：除法截断
$|\Delta r| < 2^{-p}$（$|\mathrm{d}\theta/\mathrm{d}r| \le 1$）、表系数舍入
±0.5 码、线性插值 $h^2 \cdot 0.6495/8 \cdot C$（$0.6495 = \max_{[0,1]}
|(\arctan)''|$ 为精确最大值）。实验发现该族被积函数 $e(x)^2$ 尖刺化（除法边界
处的跳变），Sobol 收敛呈非单调波动（±0.3 dB）——论文如实报告收敛特性，
并以"重评确定性"作为该层的核心承诺而非"绝对精确"。

### 4.3.4 LLR 软解调（确定性积分层 + 结构洞察）
64QAM 的每比特类按单轴比特划分，类内最小距离**可分离**：
$d_{0\min}(\text{I 轴比特}) = \min_{s_i \in S_0} d_I(s_i) + \min_{s_q} d_Q(s_q)$。
这一结构使距离网络从 64 路平方器缩减为每轴 8 路加 4 输入 (min, second-min)
网络——它本身是 ε-等价类内"保精度结构重写"的实例（与基准自带的 max-log v4
基线的 abs 距离技巧同属一类）。校正表近似主导项
$c(g) = \ln(1 + e^{-g/2\sigma^2})$（$g$ 为类内第二小与最小距离之差），参数
（表项数、小数位、输入预截断、L1/L2 距离度量）给出精度-面积折中空间。
L3 界：单点近似残差 $\le 2\sigma^2 \ln 31$ 加表量化。

### 4.3.5 模型-RTL 逐位验证

**验证协议**：对每个族取代表性参数点（覆盖不同结构分支），以相同确定性激励分别
驱动整数域模型与生成 RTL（iverilog 仿真），逐点比对输出；再以评估器的随机激励
做端到端 SQNR 对拍。

**表 4.1 模型-RTL 验证结果**（端到端 SQNR，dB）

| 族 | 参数点 | 模型(Sobol/引理) | RTL 采样 | Δ |

| cmul | so=0, sd=0 | 999（精确零误差） | 999 | 0 |
| cmul | so=4, sd=0 | 69.20 | 69.17 | +0.03 |
| cmul | so=8, sd=2, trunc, karatsuba | 45.15 | 45.17 | −0.02 |

## 4.5 重尾病态性：LLR 族的适应度估计不稳定

在 llr 族上，本文发现一个对"适应度可靠性"具有重要含义的现象。max-log 与精确
LSE 的偏差集中在"模糊点"——两类假设距离接近的星座+噪声组合。这些点数量极少
（千分之一量级）但误差巨大，使误差平方的分布呈极端重尾：

- 同一 D=0 设计（max-log）：评估器随机 $2^{16}$ 样本估计 SQNR = 53.2 dB；
  $2^{17}$ 点 Sobol 估计 = 64.1 dB——**两组"合法"估计相差 10.9 dB**；
- 机制：误差功率由期望值几乎为零的指示事件主导（泊松式到达），任何有限样本
  估计的方差由这些稀疏事件决定，采样量增加 4 倍仍不足以稳定；
- 对照：平滑族（cmul/cordic）同一设计的重评标准差实测仅 0.01~0.03 dB
  （10 次重评，秩翻转 0 次）。

**方法学含义**：(a) 对重尾族，采样适应度不仅带噪声，而且其期望本身被样本量
隐性决定——"64 dB 的 max-log"这类论文数字可能是采样伪影；(b) 确定性 oracle
的价值此时不是"更准"（它同样受格点对稀疏区域的覆盖限制），而是**可复现**——
同设计永远同一分数，进化不再追逐种子彩票；(c) 根本解法是转向 L3 口径（最坏界
或分位数界）或改用稳健统计（如误差中位数），本文按前者实现并在第五章报告其
对搜索行为的影响。

## 4.6 小结

本章建立了三级评估 oracle 及其工程实现：模分解引理使锚点任务的适应度精确化，
全枚举使一维族精确化，确定性 Sobol 使二维族可复现化，闭式界为全部族提供 sound
保证；逐位对拍验证闭环了"模型 = RTL"的语义链。证书引擎的代价结构（评估 ~1 s，
无仿真）与确定性性质，为第五章"证书携带的进化搜索"提供了物理基础。
