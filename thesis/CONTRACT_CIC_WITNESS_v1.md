## 1. 选型论证（摘要，不变）

DDC 的 E1 是单链实例。CIC 机制与之本质不同：递归状态、每级增益 ×R、溢出语义方向相反
（wrap 自愈 / sat 损伤）、折叠由 sin(x)/x 型响应塑造。局部方法锚点 = Hogenauer 1981
方差分配（经典局部方法，作最强局部基线）。实现代价低（无乘法器）。**不预期 DDC 基线③复用。**

## 2. 链定义与逐级语义（累计窗口版，钉死）

```text
x[n]（12-bit Q1.11 复基带，Fs_in = 2 MHz）
  ──▶ N 级积分器（输入率）──▶ ↓R（phase 0）──▶ N 级梳状器（输出率，差分延迟 D=1）
  ──▶ 输出寄存器（Q1.15）→ y[m]（Fs_out = Fs_in/R）
```

### 2.1 误差源与累计窗口（论文锁存口径，钉死）

误差源 j = 1..2N+1，位于**每一级输入的锁存器**（Hogenauer 1981 口径）：
j=1 为输入锁存（积分器 1 之前），j=2..N+1 为各积分器的状态锁存（= 后一级积分器
的输入；j=N+1 兼为抽取输入），j=N+2..2N 为各梳状器的输出锁存（= 后一级梳状器的
输入），**j=2N+1 为输出寄存器**。源 j 的截断误差 = 写入锁存 j 时的低位裁剪，
从该点向输出传播。

- 满精度最高位 `B_max = W_full − 1`，其中 `W_full = W_adc + ceil(N·log2 R)`
  （(2,3)→15；(2,4)→16；(4,3)→18；(4,4)→20）。
- 锁存 j（j=1..2N）保存位窗口 **[B_j, B_max]**；`B_j` 为**累计最低保留位**，沿链
  **非递减**（B_0 = 0：输入锁存从精确输入网格裁起，只裁不补）。锁存宽度
  `w_j = B_max − B_j + 1`。
- **积分器数学状态无界增长**（直流/有极性输入下不回零），有限宽度寄存器会自然 wrap；
  Hogenauer 条件**不是**让积分器永不回绕，而是**所有级共用足以覆盖最终复合滤波器输出
  的 MSB**（即 w_j = B_max − B_j + 1）：中间积分器即使回绕，模运算仍能在后续梳状器中
  自愈；sat 在相同的内部越界处钳位并破坏该性质——**这正是同宽对照的实验意义，
  不需要人为减位**。
- 每级两步（**仅内部锁存 j=2..2N**）：**扩展精度运算**（级 j 从锁存 j 读取，
  加法/差分在扩展位宽下精确完成，不丢位、不溢出）；**写入锁存 j+1**：低位裁剪
  `Δ_{j+1} = B_{j+1} − B_j` 位（rne = half-up，与 `fixed_chain.shr_round` 一致；
  或 trunc）——**该级量化误差在此产生**——再按 w_{j+1} 做高位处理：
  wrap（补码取模 2^{w}；积分器无界增长导致的回绕属设计预期，模运算在梳状器中
  自愈）或 sat（同宽度钳位到 [−2^{w−1}, 2^{w−1}−1]，在相同内部越界处破坏自愈）
  ——**溢出语义实验维度（仅内部锁存）**。输入锁存的写入只执行 Δ_1 = B_1 的
  低位裁剪（候选数值语义）；其高位对所有候选固定为**符号扩展**，永不 wrap/sat。
- **溢出事件计数**：internal_wrap_event / internal_sat_event 按**取模或钳位前的
  扩展精度状态是否超出内部锁存范围**计数（wrap 的判据 = 状态绝对值 ≥ 2^{w_j−1}），
  逐内部锁存统计；**每个场景只在场景开始时复位一次**，测量段内不得隐藏复位；
  记录**首次事件位置与逐锁存事件数**。若冻结的主场景与长度内未发生事件，O 类
  逐位相同、预注册预测失败——这是合法结果，**不得改宽度或延长序列追阳性**；
  如需展示机制，另设预注册 stress 诊断，不并入主判定。固定外部接口产生的
  output_sat（见输出寄存器条）**单独计数，不混入 O 类机制计数**。
- **输出寄存器（j=2N+1，写入公式钉死）**：格式位置 `B_fmt = ceil(N·log2 R) − 4`
  由 Q1.15 输出唯一决定（(2,3)→−1；(2,4)→0；(4,3)→2；(4,4)→4）。设
  `d = B_fmt − B_{2N}`：**d > 0** 按候选舍入模式（rne/trunc）算术右移 d 位——
  该低位裁剪为第 2N+1 源，方差增益 G=1，位置由格式固定、不参与预算分配；
  **d = 0** 原样传递；**d < 0** 左移 −d 位、新增低位补 0（精确，无裁剪误差，
  (2,3) 即此情形）。随后按**固定的 signed 16-bit Q1.15 外部接口**输出：
  饱和钳位到 [−32768, 32767]（sat16，对所有候选固定），饱和事件记 output_sat。
- 候选参数 = 非递减序列 (B_1..B_{2N}) + **内部锁存**溢出语义（wrap/sat）+
  舍入模式（内部低位裁剪的 rne/trunc）。外部接口（输入符号扩展、输出 sat16）
  对所有候选固定。manifest 记录 B_j、w_j、Δ_j、B_fmt 与尺度。

### 2.2 抽取率

`R ∈ {2, 4}`。R=8 排除：Fs_out=250 kHz 的 Nyquist ±125 kHz 放不下 ±169 kHz 信号带宽。

## 3. 场景（按 R 分套，镜像公式唯一可计算）

信号：QPSK 0.25 Msps + RRC 0.35（复用 `scenarios.py` 生成器与 seed 纪律）；信号带边缘
f_sig ≈ 169 kHz。栅格轴 = blocker 折叠落点 g（折叠后 `f' = g`）。blocker 输入频率取
±g + k·Fs_out 中**落在 (f_sig, Fs_in/2) 内的唯一频率**，按 codex 规则钉死为：

- **C_R2**（Fs_out = 1 MHz）：`f_b = Fs_out − g`（Fs_out + g 会超 Nyquist）；
- **C_R4**（Fs_out = 500 kHz）：`f_b = Fs_out + g`。

| 契约 | 主栅格 g（kHz） | f_b（kHz） | 位置检查 |
|---|---|---|---|
| C_R2 | 200,250,300,350,400,450 | 800,750,700,650,600,550 | 全部 ∈ (169, 1000) ✓ |
| C_R4 | 180,195,210,225,240,248 | 680,695,710,725,740,748 | 全部 ∈ (169, 1000) ✓ |

- 模板（每个 g）：clean + alias@g(−3 dB) + alias@g_next(−3 dB)；**g_next = 主栅格下一点，
  最后一个 g 的 g_next 取前一点**（消除"第六点无下一点"）；主契约 6×3 = **18 场景**；
- C_heldout：4 个交错落点 × 3 = 12；C_stress：主栅格 alias@g +6 dB = 6；不入主判定；
- seed：sha256(场景键) 稳定派生；AWGN：desired-only、CIC 归一化输出测量域口径。

### 4.1 H 类的 Hogenauer §IV-C 程序（钉死，论文式 (21)）

1. **方差增益 G_j**：源 j（位于每一级输入锁存）的截断误差到输出的等效 FIR
   系数平方和，全部由整数多项式精确计算（无浮点积分）：
   - 积分器级输入 j=1..N：`h_j = (1−z^{−1})^{j−1}·(Σ_{i=0}^{R−1} z^{−i})^N`，
     `G_j = ‖h_j‖²`（源 j 的误差从积分器 j 的输入进入，穿过其余 N−j+1 个积分器
     与全部 N 个梳状器）；
   - 梳状器级输入 j=N+1..2N：`h_j = (1−z^{−1})^{2N−j+1}`，
     `G_j = C(2(2N−j+1), 2N−j+1)`（含本级梳状器；j=N+1 为抽取边界锁存，
     与积分器公式在 `(1−z)^N(Σ_R)^N = (1−z^{−R})^N` 处连续）；
   - 输出寄存器源 j=2N+1：`G_j = 1`，位置由格式固定，不参与分配。
2. **预算（论文式 (21)，各源贡献近似均衡）**：每个级间源到输出的方差贡献不超过
   输出寄存器误差的 1/(2N)，纯整数判定：
   `B_j = max{ b ≥ 0 : G_j·(2N)·2^(2b) ≤ 2^(2·B_fmt) }`，
   其中 `B_fmt = W_full − W_out` 为输出寄存器丢位数（Q1.15 输出、W_adc=12 下
   `B_fmt = ceil(N·log2 R) − 4`，可为负）。
3. **单调与钳位（从后向前收紧）**：先独立取每级上限（负值钳到 0），再从 j=2N 到 1
   做反向累计最小 `B_j = min(B_j, B_{j+1})`（边界 `B_{2N+1} = max(B_fmt, 0)`；
   B_fmt < 0 时输出比内部网格更细，末级无裁剪、不构成上界），保证非递减且不超过
   任何一级自身误差上界；被 clamp/收紧的级记入 manifest。
4. **退化登记**：在 (2,3)、(2,4)、(4,3) 上论文程序不允许任何内部裁剪（全部 B_j = 0），
   H 档与 U0 位恒等，由 §4.2 等价类扫描合并；(4,4) 保留 `B = [0,0,0,0,0,0,1,2]`。
   这是论文程序在这些组合上的真实结论，不是缺陷。
5. **文献复现测试（强制，已通过）**：
   - 论文标准设计例 **N=4、M=1、R=25、Bin=Bout=16**：程序复现
     `B_j = [1, 6, 9, 13, 14, 15, 16, 17]`、`B_(2N+1) = 19`；
   - 非退化 N=3 独立例 **R=5、N=3、Win=16、Wout=12**（不被 clamp 掩盖，
     检验式 (21) 的 2N 依赖）：`B_j = [4, 6, 7, 7, 8, 9]`；
   - 逐级断言最终 B_j 满足式 (21)（实际裁剪的级）；G_j 由直接多项式卷积的独立
     实现核对。见 `tests/test_cic_hogenauer.py`。
   本节第 1–3 条的解读以这些复现为准写入生成规则与代码。

## 5. 局部指标族 M（预注册）

1. **Hogenauer 分配预测 SNR**——按 1981 原式（§4.1 的 G_j 与式 (21) 方差法）。其假设为
   **各截断误差源近似均匀且互不相关**（不是"输入必须白噪声"；输入含 blocker 不自动
   违反该假设）。实验检验它是否排错；机制解释等结果与诊断；
2. 最差级 SQNR（逐级截断噪声方差模型，同一误差源假设）；
3. 总累计裁剪 ΣΔ_j = B_{2N}（结构代价对照指标）。

容差：SQNR 类 ε_m = 0.10 dB（同 DDC）；三指标分别判定，不共享容差。

## 6. 链级契约

- **参考链三路交叉验证（钉死）**：长序列下禁止只依赖递归 float64 积分器（巨大积分状态
  经梳状器相减会损失有效位）。参考链必须同时实现 ①递归 float64、②等价 FIR/卷积形式
  （CIC 等效为 (Σ_{i=0}^{R−1}z^{−i})^N 的有限 FIR）、③无界整数实现（Python 大整数，
  逐位精确），三者输出一致后才作为参考；归一化统一除 R^N；
- `q`：bit-true 归一化输出 vs 参考的 aligned implementation NMSE（复用
  `metrics.aligned_impl_error`：前导段复标量 g、测量段、desired-only 分母）；
- `ρ`：主栅格 worst（线性域）；`ε_Q = max(q_cal, 0.1 × q_budget)`（同 DDC §5.1 推导）；
- **wrap/sat 事件计数按 §2.1 规则逐候选×场景记录**——溢出语义是实验对象，照实计 q；
  主场景无事件时如实记录"机制在该契约下未触发"。

## 7. 判据（同 PROPOSAL §2.2，预注册）

- strict reversal：`m(h_a)+ε_m < m(h_b)` 但 `Q(h_a) > Q(h_b)+ε_Q`；
- collapse：`|m(h_a)−m(h_b)| ≤ ε_m` 但 `|Q(h_a)−Q(h_b)| > ε_Q`；
- 主结论只称"本冻结栅格上的 worst"；held-out 只查稳定性；保序检验只在同 R 契约内做；
- **预注册预测**：O 类（sat 对照）在 Hogenauer 局部指标下与 wrap 版不可区分，链级可分
  ——成立则是比 DDC 更强的机制实例；不成立则登记"机制迁移失败，E 轴适用边界收窄"。
