## 1. 公共输入与 AWGN 校准

同一 R 下的 N=3、N=4 候选必须读取完全相同的 ADC 输入。为了让“输出测量域 30 dB”有唯一参考，
场景生成固定使用该 R 下的 **N=4 理想 CIC** 校准 AWGN 幅度：在前导段之后，desired-only 输出功率
与单位噪声输出功率之比缩放到 30 dB。随后得到的同一时域输入同时交给 N=3、N=4 候选，N=3 不再
单独调整噪声。

前导为 64 个符号，即 512 个输入样点；输出测量起点为 `512/R`。ADC 沿用 signed 12-bit Q1.11、
half-up 和 sat12。每个场景只在开始时复位一次。

## 2. 三路参考链

参考输入是公共 ADC 整数码，因此 ADC 误差不计入候选差异。每个 `(R,N)` 同时计算：

1. CIC 等价 FIR：`(Σ_{i=0}^{R-1} z^{-i})^N`；
2. Python 无界整数递归积分器—抽取—梳状器；
3. 递归 float64 拓扑。为防高阶积分状态增长吞掉低位，float64 状态按 `2^40` 精确取模；模数远大于
   CIC 最大输出，且所有加减保持在 float64 精确整数区间。

三路输出必须逐整数码相同。正式参考取该共同结果，再除以 `2^11·R^N`。任一路不一致即停止，不生成 q。

## 3. 局部指标的唯一计算式

设 `B_0=0`。若 `B_j>B_{j-1}`，锁存 j 产生量化源，量化步长为 `2^{B_j}` 个输入 LSB；若二者相等，
该源不存在。输出寄存器仅在 `B_fmt>B_{2N}` 时产生量化源，步长为 `2^{B_fmt}`。按上位协议的
均匀、互不相关假设，每个活动源的方差均为 `step²/12`；该局部模型只预测方差，因此 rne 与 trunc
使用同一方差，wrap 与 sat 也不进入局部预测。

源 j 的输出误差功率为：

```text
E_j = G_j · 2^(2B_j) / 12
```

输出寄存器源取 `G=1`。换算到归一化输出：

```text
e_j = E_j / (2^(2·11) · R^(2N))
```

采用单位峰值实数正弦的固定功率 `P_ref=1/2`，只提供候选无关的 dB 标尺：

```text
Hogenauer predicted SNR = 10 log10(P_ref / Σ_j e_j)
worst-stage SQNR        = min_j 10 log10(P_ref / e_j)
total cumulative pruning = B_(2N)
```

没有活动量化源时，两个 SQNR 记为 `+∞`，JSON 写成 `null` 并附 `exact_under_local_model=true`。
比较时 `+∞` 按高于全部有限值处理。0.10 dB 容差保持不变。

## 4. 链级 q

候选输出按 Q1.15 转为复数。参考输出为同一 ADC 输入的三路共同结果；desired-only 分母使用共同前端
缩放后、单独量化到 Q1.11 的 desired 分量，经同一 `(R,N)` 精确参考链得到。复增益在前导输出段
`[0,512/R)` 估计，q 在其后测量，沿用 `metrics.aligned_impl_error`。

```text
q_budget = (10^(0.10/10)-1) / 10^(30/10)
epsilon_Q = max(q_cal, 0.1·q_budget)
```

`q_cal` 用 exact-representable 相同输入校准，必须为 0；因此预期
`epsilon_Q=2.32929922807541e-6`，以运行时机器计算值为准并写入 manifest。

## 5. 执行顺序

1. 生成并锁定局部指标表；
2. 只运行 main，落盘 main checkpoint 与预注册判定；
3. 锁定 main 判定后才运行 held-out；
4. stress 只作机制诊断，不进入主判定；
5. 任何参考链不一致、manifest 指纹漂移或非有限 q 都使运行变为 inconclusive，不修改协议重试。
