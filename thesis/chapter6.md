# 第六章 总结与展望

## 6.1 工作总结

本文围绕"通信 DSP 领域数学公式到 Verilog 的自动生成"这一目标，针对现有 LLM 硬件
生成研究中"验证靠采样、算法选择靠目录、正确性口径二值化"三个结构性局限，完成了
从基准、评估体系到搜索范式的系统性工作。

**第一，构建了公式驱动的通信 DSP 硬件基准 CommDSP-Bench（第三章）。**
基准以"锁定外部行为、放开内部实现"为原则，将 3GPP 物理层算子形式化为 7 个算子族、
110 个参数化实例：任务卡是纯数学规范，golden 与激励由评估器自动生成且每次评估
使用新鲜种子（防背题），精度以 SQNR/SFDR 连续指标进入搜索。统一流式握手协议使
不同流水深度的设计在精度-面积-吞吐三维空间中严格可比。对基准的系统性审计发现并
修复了三类基线生成器缺陷（解包数组语法、case 分隔符、输出饱和缺失），识别出
重尾误差分布指标的方法学风险，最终以全量回归闭环验证了任务卡-golden-激励-基线
四件套的自洽性。

**第二，建立了证书化评估体系（第四章）。**
将评估 oracle 形式化为三级层级：L1 采样层、L2 确定性层（固定种子低差异格点或
全枚举上的整数域精确仿真）、L3 声明性层（对全体输入成立的闭式最坏界）。核心理论
结果是模分解引理及其圆卷积合成：整数域数据通路的输出量化误差只依赖输入对 $2^s$
的残差，残差分布由 2-adic 赋值混合精确给出，据此锚点任务的总体均值 SQNR 可以
零采样、零积分误差地计算。四个算子族的证书模型完成了"模型-RTL"逐位对拍验证
（平滑族端到端偏差 < 0.1 dB，LLR 族逐位零失配）；实验同时揭示了重尾误差分布下
适应度估计的固有病态性——这一发现将"为什么需要证书"从工程直觉提升为可量化的
方法学论据。

**第三，提出并验证了证书携带的进化搜索范式（第五章）。**
让 LLM 在"证书携带的参数化模板空间"中进化：每个候选是模板空间的一点，精度由
证书引擎确定性给出、面积由真实综合获得，算法结构（CORDIC/查表/插值/截断策略）
成为一等搜索自由度。以 DeepSeek deepseek-flash 为后端的同预算对比实验显示：
证书携带空间中的进化在锚点任务上找到了采样基线完全错过的精度可谈判点
（57.2 dB/2804 LUT），在正余弦任务上第 5 次迭代即跨越采样基线 40 次迭代未能
突破的算法类地板（93.99 dB vs 75.6 dB），并将低面积多周期的 CORDIC 分支纳入
同一前沿；最终重判确认了证书预测与实测的一致性。配套的确定性实验进一步表明：
(a) 证书引导的等价类导航以一个数量级更少的综合预算恢复全量 Pareto 前沿；
(b) 以 BER 证书（而非 SQNR 门槛惯例）选型匹配滤波器系数字宽可节省 66% 面积；
(c) 平滑族的新鲜种子采样噪声仅 0.01~0.03 dB，而重尾族的估计不稳定——证书
的确定性价值随指标病态性增长。

## 6.2 创新点

1. **基准层面**：首个以数学公式为输入、以连续精度为一等搜索维度、原生防背题的
   通信 DSP 硬件基准，及其系统化审计与修复方法论（第三章）；
2. **评估层面**：评估 oracle 三级层级与模分解引理——把"适应度"从随机变量改造为
   在满足条件时可精确计算的数学对象，并给出模型-RTL 逐位验证的完整证据链
   （第四章）；
3. **搜索层面**：证书携带的进化搜索范式——LLM 的角色从"自由文本生成器"转变为
   "证书携带空间中的导航算子"，以结构跳变的可系统性触达取代采样赌博
   （第五章）。

## 6.3 局限性

本文工作的边界同样需要明确：

1. **算子规模**：基准任务为单模块量级（数十至数百行 RTL），未覆盖仓库级设计、
   协议交互与复杂控制流。证书模型的族特化设计依赖每族一次的人工数学建模——
   族数量增长时该成本线性增长，其自动化（从任意公式自动推导证书）是未解问题；
2. **LLR 校正路径**：软解调族的单主导项校正结构在 RTL 层存在待修复的实现缺陷
   （论文 4.3.4 节如实记录），当前该族证书空间仅开放 max-log 口径；重尾指标的
   适应度估计在确定性 oracle 下仍非"准确"，只是"可复现"；
3. **实验规模**：受 API 预算约束，E1 主对比为单种子（seed 0）、四任务、40 迭代；
   统计显著性（SPEC §7.4 的 5 seeds + Wilcoxon）未达论文主表的理想标准，第五章
   的结论以效应量（前沿差异的幅度）与机制消融的一致性作为补充证据；
4. **综合口径**：面积基于 Yosys 开源综合（ice40 与 Nangate45），未覆盖商用工具
   的时序收敛与功耗；吞吐为接口层实测值，未做物理时钟域分析。

## 6.4 展望

**近期（可直接延续本文基础设施）**：
- 将 SPEC §7.4 的多 seed 统计协议跑满（5 seeds × 4 任务 × 两臂），并把 LLM 后端
  扩展到第二个模型以检验方法-后端无关性；
- 补齐 scrambler（GF(2) 并行展开）与 64 点 FFT（R2²SDF/R4MDC 架构族）两个任务族，
  使基准覆盖"物理层算子集"的最后缺口；
- 修复 LLR 校正路径的 RTL 缺陷，开放完整的校正表参数空间。

**中期（方法延伸）**：
- **精度感知的等价饱和**：把第四章的 ε-等价类与 e-graph 结构合并——重写规则携带
  误差合成律，饱和过程直接在"精度-成本"联合空间展开，取代手工参数化模板。这将
  "算法目录导航"推广为"任意公式空间导航"，并与 ASPEN 等 LLM 生成重写规则的工作
  形成直接对话；
- **含环结构的归纳不变量推断**：NCO/IIR/PLL 类任务的证书需要循环不变量——让
  LLM 扮演猜想者、区间求解器扮演裁决者，是免训练 LLM 在 EDA 中最自然的位置之一；
- **LLM 与证书工具的分工协议**：本文的模板证书是族特化的；通用化路径是让 LLM
  生成 Gappa/Sollya 风格的证明义务，由求解器裁决，形成"生成的代码携带其自身的
  正确性证明"的合成闭环。

**远期（系统性愿景）**：
从算子级到链路级——以端到端 BER/EVM 证书为全局约束，把误差预算自顶向下分摊到
收发链的每个算子（WCPG/仿射算术给出预算的解析传播），每个算子内部运行本文的
证书携带搜索。"通信系统的证书化综合"——设计者只写数学规范与系统指标，工具链
输出携带误差证书的整链 RTL——是本文路线的最终形态。
