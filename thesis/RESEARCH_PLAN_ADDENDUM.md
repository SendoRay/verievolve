# 研究计划补充：P0 结果复核与下一阶段实施

日期：2026-09-28  
基准：[RESEARCH_PLAN.md](RESEARCH_PLAN.md)，尤其 §6、§7、§9、§11。  
范围：在现有 DDC 工作上补齐证据与方法，不替换原计划。按硕士课题、LLM API 可用但不训练模型的条件组织。本文是审查与实施建议；没有修改已有实验代码、结果或计划。

## 1. 总体判断

新增工作有效地推进了课题：已有文献差距表、复乘模型修复与回归、DDC 浮点/整数参考、96×15 数值实验、RTL 生成器、代表设计对拍和 48 个综合面积结果。现在最需要的不是再铺开一个研究方向，而是把这些产物组织成一条可信的证据链。

**当前阶段应定位为“试验台已建立，研究假设待进一步核验”。**

| 原计划事项 | 本次判断 | 下一步 |
|---|---|---|
| 数值模型修复 | 复乘修复与回归已形成资产，不必重做 | 将回归接入后续自动验收 |
| H1：局部信息影响系统筛选 | 已有观察，但关键预测器与比较口径存在问题 | 修正后重算，区分排序变化与真正的设计损失 |
| H2：联合选择改善硬件 | 尚未得到支持；S2 中 staged 与枚举没有面积差距 | 加入公平时序/吞吐约束与明确搜索基线，再检验 |
| H3：跨规格复用节省成本 | 尚无必要启动；报告中 S1 全池约 7 秒 | 只有确认实际评估瓶颈后才考虑 |
| RTL 与物理评估 | 有连续流前缀对拍和综合面积，不等于完整协议验证及物理实现 | 补验收契约、时序与最终设计物理复测 |
| LLM 辅助自动化设计 | 当前新增 S1/S2 主要验证候选和评价器，还未验证 LLM 方法 | 明确 API 提议什么、反馈什么、相对谁改进 |

因此不宜把“存在 420 对错筛”“研究空缺成立”“联合优化初步有效”直接作为论文结论。下面区分已定位的实现问题、需要验证的机制和拟开展的方法研究。

## 2. 最高优先级：先校准评价器和比较口径

以下路径均相对于 `examples/comm_dsp_bench/`。

### 2.1 L3 抽取折叠索引错误：必须先修复

位置：`chains/ddc/metrics.py::spectral_prediction`。

注释写的是：

```text
P_fold[k] = sum_j P_in[k + j * N_out]
```

实现却是 `p_fold += p_in[j::R]`。它把相邻输入频点分组，而不是把相隔输出采样率的频点折叠到同一个输出 bin。

本次独立检查使用 `N=4096`、`R=2`、`h=[1]`、`fir_err=0`、参考功率 1，单个 FFT 栅格复指数叠加约 1e-6 幅度噪声；比较当前预测与直接抽取后的带内功率：

| 输入频率 MHz | 当前预测 dB | 直接抽取真值 dB |
|---|---:|---:|
| 0.2998046875 | 约 0 | 约 −121.08 |
| 0.849609375 | 约 −121.12 | 约 0 |

这是频带映射错误，不是误差独立性假设失效。数字只是单元诊断，不代表真实 DDC 的损失幅度。

新增任务与验收：

- [ ] 使用正确的折叠索引，并检查 FFT 归一化与抽取相位。
- [ ] 加入正/负单音、通带/阻带、折叠进通带的参数化单元测试。
- [ ] 分开验证“功率相加近似”和“复幅度相干相加”：即使索引正确，同一误差源的不同频率副本也可能相干，功率折叠并非任意确定性信号的精确公式。
- [ ] 新版本重算 S1；旧结果保留为历史记录，不覆盖后继续沿用原结论。

### 2.2 预测值与真值目前不对应同一个量

`spectral_prediction` 只积分 `|f| <= 0.20 MHz`；`run_s1.py` 中的 `truth_err_db` 是 `aligned_impl_error` 返回的 **raw、全带、去除前导后的时域误差**。预测分母又使用包含前导的参考功率。另一个 `inband_error_db` 使用带内信号作分母，也不是同一口径。

此外，当前先截断 `e_mix`，再用同长度 FFT 乘以 FIR 频响，相当于循环卷积；真实参考是带历史状态的线性卷积，两者边界并不相同。

新增任务与验收：

- [ ] 建立唯一的指标说明：误差定义、频带、参考功率、暖机段、对齐段、测量段、符号及单位。
- [ ] 主结果优先使用 raw 实现误差；aligned 误差单独报告增益/相位校正收益，不能混用。
- [ ] 先用时域线性滤波得到误差分量，再按一致窗口计算频域诊断；优化为 FFT 时另做等价性测试。
- [ ] 对全带指标验证 Parseval 一致性；带内预测只和相同窗口、分母的带内真值比较。
- [ ] 明确实现误差不等于通信总 EVM，更不直接给出 BER 保证。

### 2.3 L1 的 SFDR 测量存在主瓣泄漏问题

位置：`metrics.py::sfdr_db`。Blackman–Harris 加窗后仅排除峰值附近 ±2 bin。以当前 65536 点长度和三个频移测试没有量化误差的理想余弦，得到：

| 频率 MHz | 当前函数返回 SFDR dB |
|---|---:|
| 0.39 | 22.80 |
| 0.51 | 26.84 |
| 0.63 | 31.14 |

这表明测量受到窗主瓣泄漏显著限制。现阶段不能把 L1 的负相关归因于“SFDR 指标本身误导”。

- [ ] 用理想单音与已知幅度/频率的附加杂散校准测量器；给出检测动态范围。
- [ ] 根据窗响应确定主瓣排除范围；同时用相干采样测试交叉验证。
- [ ] 重新计算 L1，并与“杂散幅度+位置+下游传递”的强基线区分。

### 2.4 其他应顺手修正的统计与场景问题

| 位置 | 已观察问题 | 建议验收 |
|---|---|---|
| `run_s1.py` 的 `worst_drop` | 两个反转分支把 `kept` / `dropped` 写反；计数与案例标签要分开处理 | 人工构造两个候选，检查预测差、真值差、保留/淘汰标签 |
| `run_s1.py` 的 NCO 轨迹 SQNR | 把实数两列数组交给按复数实/虚字段拆分的函数，得到合并功率比而非两字段最差值 | 使用复数编码或明确逐列归约，与手算一致 |
| `run_s1.py::kendall_tau` | 当前归一化是 tau-a；候选中有 ties | 明确统计口径，增加 tau-b 与并列最优集合保留率 |
| `scenarios.py::qpsk_symbols` | 注释说平均功率 1，实际约 0.5 | 选择一个规范并统一实现、注释、SNR 与符号 EVM 校准 |
| `scenarios.py` 的 AWGN | 在叠加 blocker 后计算 `p_sig`，SNR 实际相对信号与干扰之和 | 明确 desired-signal SNR 或总输入 SNR；改变 blocker 时控制噪声基准 |
| 场景归一化 | 以整段波形峰值决定缩放，未输出实际增益 | 记录缩放系数、实际信号/干扰/噪声功率和 ADC 饱和数 |
| `spec.py` 的 alias 描述 | +0.55 MHz 抽取后为 −0.45 MHz；在输出 Nyquist 带内，但不在 ±0.20 MHz 信号通带内 | 区分两个“带内”；若检验折叠进信号带，在新版本预注册相应场景 |

这些问题不意味着已有全部数据无效；必须逐项标记哪些字段可直接重算、哪些需要重新运行。修复评价器不计为研究创新，但它决定创新论证是否可信。

## 3. 先解释机制，再设计新的筛选方法

### 3.1 建立精确误差分解作为诊断参照

令 `x_c` / `x_r` 为候选/参考混频输出，`F_c` 为候选定点 FIR，`H` 为理想线性 FIR。在相同裁剪和抽取操作 `D` 下：

```text
u = D H(x_c - x_r)
v = D [F_c(x_c) - H(x_c)]
e_out = u + v
P(e_out) = P(u) + P(v) + 2 Re mean(u * conj(v))
```

这里 `v` 已经包含系数量化、舍入及饱和。即便 `F_c` 非线性，上述代数恒等式仍成立；不能再把测得 `v` 后的残差简单归因于“遗漏饱和”。

本次检查 `alias_f390_b550_r6`、首个 NCO、`f5_c12_acc24`、首个复乘候选：FIR 饱和计数为 1342，`max|e_out-u-v|` 约 `1.68e-16`，与该恒等式一致。

新增实验：

1. 同窗口下比较真实误差、`P(u)+P(v)` 和加入交叉项后的结果。
2. 分开测量滤波边界处理、抽取副本相干性、级间相关性带来的偏差。
3. 用相同符号/噪声及受控干扰相位，只改变一个因素；再用独立种子验证。
4. 分别分析无饱和和有饱和候选，不预设哪种因素主导。

验收：完整分解在浮点容差内闭合；某一简化项被移除后，才能将差异归因于该近似。选取少量代表案例即可，不需要先扩大到另一条通信链。

### 3.2 区分诊断上限与便宜预测器

当前 L3 的 `fir_err` 来自实际运行候选 FIR，`e_mix` 也来自实际候选混频。因此它是利用候选轨迹的诊断基线，尚不能证明“不运行完整组合即可便宜筛选”。

需要记录每类信息的获得代价：解析计算、模块仿真、链路仿真、综合、物理实现、API 调用。即使能缓存，也应计入首次构建成本和缓存失效条件。

只有明确当前耗时瓶颈之后，才决定要节省哪类评估。对本轮约 7 秒的数值全枚举，加入 API 调用未必更划算；自动化方法应把额外成本算进去。

### 3.3 将“错筛”转化为实际决策损失

排序反转不等于选错最终硬件。420 个候选对也不是 420 次独立实验。

对固定规格、候选全集 `C`、可行集合 `F`、筛选保留集合 `S`，定义：

```text
A* = min area(c), c in C ∩ F
A_S = min area(c), c in S ∩ F
area_regret = A_S / A* - 1
```

若 `C∩F` 非空但 `S∩F` 为空，单独记“丢失全部可行解”，不能用任意大面积替代。若全集无可行解，记规格不可行，不计为筛选失败。

至少报告：可行解命中率、并列最优集合命中率、面积 regret、固定预算下的最佳可行面积、总评估成本。排序相关系数和预测误差仅作为辅助诊断。不同方法使用相同候选访问规则、初始信息、场景和预算。

S2 当前无面积损失是有价值的负结果。不要仅为产生正结果而扩大候选池、调紧阈值或改变 top-K；任何扩充都应由部署要求或具体机制驱动，并在新测试前冻结。

## 4. 硬件侧必须新增的检查

### 4.1 RTL 对拍：从前缀一致提升为明确契约下的验收

`rtl_equiv_test.py` 使用 `n=min(len(rtl), len(reference))`，没有断言输出数量；因此短输出可能漏检，极端情况下零输出也得到零失配。TB 在输入结束后仍保持 `in_valid=1` 并重复最后输入。

`rtl_gen.py` 暴露 `in_valid`，但状态按连续流每周期推进，没有实际消费该信号。不能把当前测试标成完整握手/协议边界回归。

- [ ] 明确只支持连续流，还是支持输入气泡；若只支持连续流，接口和断言应清楚表达限制，不必为了论文强加 ready/valid。
- [ ] 建立按输入样本编号的 scoreboard，严格校验每个期望输出的数量、顺序、延迟和数值；连续流的观测窗口与尾部输入应明确建模。
- [ ] 对零输出、少输出、重复输出、仿真失败、X/Z 设置明确失败条件。
- [ ] 避免复位释放与采样沿竞争；补复位中断、极值输入、舍入边界、饱和和抽取相位测试。
- [ ] 至少对所有进入最终 Pareto 集和论文主表的设计逐一验证；代表测试不能替代它们。

### 4.2 综合面积必须对应同一个被评价的硬件

`run_s2.py` 固定以 0.39 MHz 生成 FCW；RTL 将其写成 `localparam`。质量却取 0.39/0.51/0.63 MHz 全部场景的最差值。目前这是“单一固定 FCW 实现的面积 + 多 FCW 配置族的质量”，不是已经验证的同一可调频硬件。

建议选择并冻结一种契约：

- 可调频 DDC：FCW 是运行时输入/配置寄存器，所有场景使用同一个 RTL hash，评估频率更新规则。
- 固定频率设计族：分别生成和综合不同 FCW 的 RTL，分别关联质量，明确面积如何聚合。

不要假设常数传播对各 FCW 的面积完全没有影响。

### 4.3 体系结构比较：统一服务率，而不只是都标 II=1

当前面积结果没有时序约束，不能证明设计在指定时钟下可行。下一步冻结时钟、输入服务率、输出抽取率、允许延迟、接口与数值语义。

若输入仅 2 Msps、时钟取 100 MHz，平均每输入样本有 50 个时钟周期；资源复用架构可能满足需求。把所有候选都限制为每周期处理一个输入，会排除重要的面积—吞吐折中。反之，若应用必须 II=1，应给出需求依据。

首轮只新增一个有明确意义的硬件结构轴，例如全并行与受限资源复用；不要同时铺开多相、CIC、FFT、调度器等所有方向。结构变化必须保持相同外部契约；若量化位置变化导致数值差异，重新进行链路评价。

- [ ] 综合与 STA 使用统一库、时钟/IO 约束、角和脚本；单独报告不满足时序的候选。
- [ ] 参考设计、各基线最优及所提方法最优做相同物理流程复测；最终数量由预算决定。
- [ ] 尚无 Linux/物理资源时，继续做口径修复与机制实验，结果明确标为综合/STA，不声称 post-route PPA。
- [ ] 未测开关活动与功耗时，仅报告面积、时序及成本，不补写功耗收益。

## 5. API-only 条件下，建议怎样形成一个硕士研究方法

### 5.1 一个主问题，而不是三个独立课题

建议收束为：

> 在给定 DDC 场景集合、数值质量和吞吐/时序约束下，如何利用链路误差反馈指导候选实现的生成与选择，在有限设计评估预算内获得更好的可行硬件？

H1 为设计方法提供机制依据，H2 检验其硬件价值；H3 暂作为可能的实现优化。模型训练不是前置条件，API 只是候选提议器。是否有研究贡献，取决于反馈与决策机制是否有效，而非有没有修改模型权重。

### 5.2 首个方法原型的边界

建议采用受限配置或结构变更提议，而不是一开始允许任意重写整条接收机：

1. 输入：当前合法设计、约束、候选实现说明、数值/硬件瓶颈和历史评估。
2. LLM 输出：结构化变更，例如 NCO 实现切换、指定量化点位宽调整或已支持的资源复用配置；注明预计影响和需要复验的部分。
3. 确定性执行器：检查合法性，生成 RTL 和整数模型，运行功能、质量及硬件检查。
4. 反馈：返回违规原因、相关频带误差、饱和、硬件瓶颈与真实成本；由实验比较反馈粒度，而非预设越详细越好。
5. 决策：维护可行 Pareto 集和预算，拒绝不合法变更，保留所有失败及修复成本。

第一版优先回答“结构化链路反馈是否改善提议和选择”。固定候选池足以做该机制对照，但不能据此声称发现了新架构。若后续主张候选生成能力，需要单独统计新候选及其验证、性能与成本，并让生成基线享有相同动作权限。

### 5.3 必须具备的比较与消融

| 比较对象 | 用途 |
|---|---|
| 小空间全枚举 | 参考最优与 regret；不当作大空间的等预算在线方法 |
| 分阶段选择、交替局部搜索 | 对应原计划 H2，不能只设弱局部 SQNR 基线 |
| 至少一种非 LLM 搜索，如进化搜索或适用的 BO | 判断收益是否只是搜索预算或算法带来的 |
| 同一 API 模型，仅最终质量/面积反馈 | 隔离结构化链路反馈的价值 |
| 同一 API 模型，加入本方法反馈 | 所提方法 |
| 非 LLM 搜索使用相同误差信息 | 判断贡献来自信息、决策策略还是 LLM 的使用方式 |

传统谱/杂散强基线仍须完成校准；论文方法无法完全复现时，清楚标注“依据其机制实现的适配基线”，不写成原作者方法的原样复现。

公平性要求：

- 同一组初始设计、动作空间、质量阈值及评估器；无效提议、重试、超时全部计入成本。
- 同时记录候选次数、昂贵评估次数、墙钟时间、API token/费用；只对齐调用次数不够。
- 缓存规则与初始缓存一致；离线表可用于受控搜索回放，但另做端到端成本测量。
- 记录模型标识、可获得的版本信息、采样参数、完整请求/响应与解析失败，不假定闭源 API 永久可复现。
- 先预注册多个独立搜索种子，例如 5 次作为起点；不足以区分效应时增补重复，不把一次最优轨迹当平均收益。

## 6. 文献与论证还需补什么

`LIT_GAP.md` 已明确标出部分论文只读到摘要或引用网络，这是好的基础。本次主要检查仓库及数值实现，未重新独立核验其中每项文献论断。

下一轮只优先补读最影响基线定义的材料：R2 的解析精度/架构迭代机制、Novo 的场景定义、Nicholas 公式适用条件，以及直接影响 API 提议与反馈方法的先例。将相应假设映射为可运行基线，而不仅增加文献数量。

需要收紧两类表述：

- “未检索到同样工作”只支持待检验的差距假设，不能证明“别人没做”。
- “最小充分集合”需要定义任务分布、允许的决策误差、充分性的含义及最小性论证。硕士阶段可先研究“低成本误差描述对设计决策的作用与适用范围”，通过逐项消融呈现证据，不提前承诺普遍最小性定理。

保留原计划的近年文献线索，但应按最终方法范围更新直接比较对象；不需要先做全面综述才能继续修复实验。

## 8. 阶段决策：什么证据值得继续

**关口 A：修复后，强基线仍导致可测的设计损失吗？**

- 有：围绕可定位的误差机制提出反馈/筛选方法。
- 无：保留负结果；停止把该错筛现象作为主要动机。只有实际存在其他瓶颈时，才转向候选生成或设计成本问题。

**关口 B：同预算下，方法是否比强搜索基线更好？**

- 有更好的可行硬件，或相同质量下更低总成本：继续做外推与物理验证。
- 只有预测相关系数提升，没有决策或成本收益：不能宣称设计自动化收益。
- 非 LLM 方法同样有效：将贡献定位于误差信息与设计决策方法，LLM 是可选实现；不要把 API 调用本身包装成贡献。

**关口 C：结论能否在未调参的数据和真实约束下保持？**

开发阶段已经观察过的 15 个场景只作开发集。新增确认集应在调参前冻结，至少包括未见频移/干扰条件与独立种子；若主张跨规格能力，再增加未见规格。效应阈值依据工程意义和测量波动预注册，不依据已看到的收益倒推。

最终最低交付应是一条完整链条：**明确的设计问题 → 经过校准的强基线 → 有针对性的自动化方法 → 同预算收益 → 适用边界与可复现实验。** 一个 DDC 子链也可以承载这条链条；研究充分性来自证据，而不是再增加三个独立课题。
