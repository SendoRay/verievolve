## 1. 输入：(F, M, T)

```
任务名：dev_r32_narrow

F（公式）
    y[m] = ↓R { h * ( x[n] · e^{-j 2π f_if n} ) }
    含义：把实数 ADC 输入中，中频 f_if 处 ±passband 的信号搬到零频，
          低通滤波，再抽取 R 倍，输出复基带 I/Q。h 不指定，只要求满足指标。
    参数（频率都按输入采样率归一化）：
        R         = 32
        f_if      = 0.2471      （频率控制字 fcw = 1061286419 / 2^32）
        passband  = 0.00625     （通带半宽）
        fs_out    = 1/32 = 0.03125

M（指标，含测试信号环境）
    测试信号 = 期望信号 + 干扰 + ADC 量化
        期望信号：通带内的多个单音
        干扰：    覆盖“所有会折叠进通带的频段”的强阻塞，
                  每个混叠带 2 个随机频点，总功率比期望信号高 10 dB
        ADC：     12 位量化
    搜索场景：0、1（设计时可见）
    留出场景：10、11、12（设计时不可见，只用于最终复核）
    指标：
        SNR  = 期望信号功率 / (输出中其余一切：漏进来的干扰 + 量化噪声 + 失真 + 杂散)
        纹波 = 通带内增益起伏

T（允许空间 + 接口）
    SNR 门槛 = 理想接收机的 SNR − 1.5 dB
                场景 0：60.30 − 1.5 = 58.80 dB
                场景 1：61.20 − 1.5 = 59.70 dB
    纹波     ≤ 0.5 dB
    接口     输入 12 位有符号实数，每拍 1 个样点；输出 16 位有符号 I/Q，每 32 拍 1 个样点
    （设计时额外要求 0.3 dB 安全裕量）
```

“理想接收机的 SNR”的意思：拿同一份带干扰、带 ADC 量化的输入，用无限精度、理想滤波器算一遍，能达到的 SNR 就是上限。实现只允许比它差 1.5 dB。

## 2. 第一份 IR：自动生成的直写程序

系统把 F 的每个数学运算，按“最直白、精度足够”的方式展开成原语：

```python
# 直写起点（自动生成）：任务 dev_r32_narrow
def build(g, spec):
    x = g.input()
    # 频谱搬移 x·exp(-j2π·f0·n)：相位累加器取高 16 位查整周期正余弦表
    ph = g.counter(1061286419, 32)
    addr = g.bits(ph, 31, 16)
    cos = g.lut(addr, [math.cos(2*math.pi*k/65536) for k in range(65536)], 20, 18)
    sin = g.lut(addr, [math.sin(2*math.pi*k/65536) for k in range(65536)], 20, 18)
    with g.scope("mixer"):
        i1 = g.q(g.mul(x, cos), 22, 20)
        q2 = g.q(g.neg(g.mul(x, sin)), 22, 20)
    # 理想低通的直写实现：通带到 0.00625，阻带从 0.025 起，100 dB 衰减
    fp, fstop = 0.00625, 0.025
    ntaps, beta = scipy.signal.kaiserord(100.0, (fstop - fp) / 0.5)
    h = scipy.signal.firwin(ntaps | 1, 0.5*(fp + fstop), window=("kaiser", beta), fs=1.0)
    with g.scope("lowpass"):
        i5 = g.mac(list(zip(g.delay_line(i1, len(h)), h)), coef_bits=22)
        q6 = g.mac(list(zip(g.delay_line(q2, len(h)), h)), coef_bits=22)
    d7 = g.decimate(i5, 32)
    d8 = g.decimate(q6, 32)
    with g.scope("output"):
        o0 = g.q(g.shift(d7, 3), 16, 15)
        o1 = g.q(g.shift(d8, 3), 16, 15)
    g.output(o0, o1)
```

运行后得到的数据流图（全部在输入速率上运行）：

```

                         │                                                            │
 x[n] 12b ──────────────┬┼──────────► [mul] ─► [q 22b] ─► [delay_line ×343] ─► [mac 343 抽头] ─► [decimate ÷32] ─► [shift] ─► [q 16b] ─► I
                        ││              ▲                                                       │

```

## 4. LLM 的一次结构变换（真实发生过的）

下面这次变换取自 Claude agent 的设计过程。它先用分析判断：“滤波在全速率上做太贵，应该先用只有加法的 CIC 把速率降下来，再在低速率上补偿”；同时把 6.5 万项的大表换成“小表 + 一阶插值”。

### 4.1 改写前后对比

```
改写前（直写）                                   改写后（候选 c09）
─────────────────────────────────────           ──────────────────────────────────────────────
NCO：65536 项整表 ×2                             NCO：256 项小表 + 6 位相位做一阶插值修正
     （2.6 Mbit 存储）                                （约 11 kbit 存储 + 2 个小乘法器）

混频：x·cos, −x·sin，22 位                       混频：x·cos, −x·sin，截到 15 位

滤波：343 抽头 FIR，全速率，每路 333 个非零常乘        滤波：
      → 然后才抽取 ÷32                                 6 级积分器（全速率，只有加法）
                                                      → 抽取 ÷32（先降速！）
                                                      → 6 级梳状器 y[t]−y[t−1]（低速率，只有减法）
                                                      → 7 抽头对称补偿 FIR（低速率，补偿 CIC 下垂）

输出：×8 后量化到 16 位                           输出：×8 后量化到 16 位（不变）
```

这里用到了三种变换：

| 变换 | 类型 | 说明 |
|---|---|---|
| 长 FIR → CIC + 小补偿器 | **近似**（非等价） | CIC 的阻带和理想低通差很多，数学误差很大；但差的那些频率上没有干扰，或者被补偿器滤掉了 |
| 先抽取再滤波 | 等价 | 梳状器和补偿器挪到抽取之后，在 1/32 的速率上运算 |
| 大表 → 小表 + 插值 | 近似 | 正余弦值有微小误差，只要产生的杂散不把干扰搬进通带就可以接受 |

### 4.2 改写后的 IR（关键部分）

```python
P = dict(P=8, D=6, wl=14, cw=7, mix_w=15, N=6, R=32, K=3, band=0.185, comp_bits=14, ...)

def build(g, spec):
    x = g.input()
    with g.scope("nco"):
        cos, sin = nco(g)                     # 256 项表 + 一阶插值修正
    with g.scope("mixer"):
        i1 = g.q(g.mul(x, cos), 15, 14)
        q1 = g.q(g.neg(g.mul(x, sin)), 15, 14)
    def cic(s):
        for j in range(6):                    # 6 级积分器，全速率，只有加法
            s = g.integrate(s, ...)
        d = g.decimate(s, 32)                 # 先降速
        for j in range(6):                    # 6 级梳状器，低速率，只有减法
            d = g.q(g.sub(d, g.delay(d, 1)), ..., ovf='wrap')
        return g.q(g.shift(d, -30), 20, 18)   # 除以 32^6 的增益
    with g.scope("cic"):
        ci = cic(i1); cq = cic(q1)
    c = comp_design(32, 6, 3, 0.185)          # 离线设计 7 抽头补偿系数（numpy 最小二乘）
    def comp(s):
        dl = g.delay_line(s, 7)
        terms = [(dl[3], c[0])] + [(g.add(dl[3-k], dl[3+k]), c[k]) for k in range(1, 4)]
        return g.mac(terms, coef_bits=14)     # 对称预加：7 抽头只要 4 个乘
    with g.scope("comp"):
        oi = comp(ci); oq = comp(cq)
    with g.scope("output"):
        g.output(g.q(g.shift(oi, 3), 16, 15), g.q(g.shift(oq, 3), 16, 15))
```

改写后的数据流图：

```
          ┌──────────── 全速率 ────────────────────────────────┐ ┌──── 1/32 速率 ──────────────────────────────────────┐
x[n] ─┬──► [mul]─►[q15] ─► [∫]─►[∫]─►[∫]─►[∫]─►[∫]─►[∫] ─► [÷32] ─► [Δ]─►[Δ]─►[Δ]─►[Δ]─►[Δ]─►[Δ] ─► [补偿 7 抽头] ─► [q16] ─► I
      │     ▲                                                       │
      │  [NCO：counter → bits → lut 256 项 + 插值修正（2 个小乘法）] │
      │     ▼                                                       │
      └──► [mul]─►[neg]─►[q15] ─► [∫]×6 ────────────────────► [÷32] ─► [Δ]×6 ─────────────────► [补偿 7 抽头] ─► [q16] ─► Q

  [∫] = integrate（累加器）   [Δ] = y[t] − y[t−1]（梳状器）

 图统计：158 个节点（直写为 1370）；4 个变量乘法器；8 个常系数乘；查找表 11,264 bit（直写为 2,621,440）
```

## 5. 先看一次失败：c08（5 级 CIC）

在 c09 之前，agent 先试了 5 级 CIC（c08），面积更小，但没有达标：

```
┌─ c08：CIC 5 级 ────────────────────────────────────────────────────────┐
│ 场景 0：SNR 60.30 dB  门槛 58.80  → 达标                                  │
│ 场景 1：SNR 58.13 dB  门槛 59.70  → 不达标（差 1.57 dB）                   │
│ 代理面积 23,853                                                           │
└──────────────────────────────────────────────────────────────────────────┘

反馈给 LLM 的不是“失败”两个字，而是：
    · 场景 1 差 1.57 dB，场景 0 还有余量 → 问题只在某些干扰位置上
    · 逐段面积：cic 13,299 / comp 6,023 / mixer 2,186 / nco 1,731
LLM 的诊断：场景 1 在“第一个混叠带的边缘”有强干扰，5 级 CIC 在那里只有约 −63 dB 抑制，不够。
LLM 的修改：CIC 改成 6 级 → 就是下面的 c09。
```

这一步说明了第 3 节讲的“通信误差”：5 级 CIC 在大多数频率上都够用，只有当干扰恰好落在混叠带边缘时才不够。单看 CIC 本身的数学误差，看不出这件事。

## 8. 判定细节：SNR 是怎么算的

```
       期望信号（通带多音）──┐
                            ├──► 相加 ──► ADC 12 位量化 ──► 带干扰的输入 x[n]
       强阻塞（覆盖混叠带）──┘                                     │
                                                                   │
```

## 9. 说明

1. 第 4–7 节的变换和设计由 Claude agent 完成：它只拿到任务契约、原语说明、直写示例和评价工具。契约是人工编写的。
2. “逐段面积”是代理估计（与真实面积的秩相关为 1.0，误差中位数 4.8%）；PPA 一栏是真实综合加 OpenSTA 的结果。功耗用的是全局翻转率 0.1、时钟 2 ns，只适合横向比较。
3. 最终设计的留出场景复核还没做。它的积分器最高位是按测试信号峰值设的，如果信号更强会回绕，所以留出复核是必要的。
