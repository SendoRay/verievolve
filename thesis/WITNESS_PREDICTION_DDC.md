## 1. 链路与误差分解

`spec.py` 冻结：`Fs_in = 2 MHz`，32 位相位累加器，相位字取高 `B` 位；复混频
`y = x · conj(m̂)`；33 抽头对称 FIR（通带 0.20 MHz，阻带 0.45 MHz，≥35 dB）；抽取 `R = 2`；
QPSK 0.25 Msps、占用带宽 ±0.169 MHz。

NCO 误差 `δm = m̂ − m` 对输出的贡献在混频处是**严格线性**的：

`e_out ≈ D · H · (x · conj(δm)) + (CMUL / FIR 自身舍入项) + (二者交叉项)`

`x` 包含**所有**输入分量（期望信号、blocker、AWGN）。所以 NCO 误差不仅作用于期望信号，还会把
blocker 搬进带内。这正是模拟接收机里的 reciprocal mixing 在数字 NCO 上的对应物。

两类误差结构（决定「被抓进带内的比例」）：

| 类型 | 来源 | 谱结构 | 带内捕获比例 |
|---|---|---|---|
| **杂散型** | 相位截断（DDS 经典）、LUT 最近邻的相位量化 | 少数离散谱线，位置由 FCW 决定 | 0–≈60%，随 FCW 剧烈变化 |
| **宽带型** | CORDIC 残余角、表项舍入 | 大量小谱线，近似白 | 近似常数 ≈ 带宽占比 |

带宽占比的估计（白误差）：若 `q` 取整个输出带的实现误差，FIR 通过比例约 0.3；若 `q` 取符号域
（匹配 RRC 后）的实现 EVM，只剩信号带 ±0.169 MHz，约 0.17。**这对预测的量级有直接影响**，
见第 3.3 节，需与 Codex 的 `q` 定义对齐。

### 1.1 各类误差的估算公式

- **相位截断到 `B` 位**：`Δ = 2π / 2^B`，floor 截断的均值 `Δ/2` 是常数相位偏置，会被 LS 增益 / 相位
  对齐吸收；剩余方差 `Δ²/12` → 对齐后 `SNR ≈ 6.02B − 5.17 dB`。误差序列是锯齿波，基频
  `f_e = frac(FCW / 2^(32−B)) · Fs`（折回 ±Fs/2），第 `k` 次谐波功率占比 `(6/π²)/k²`：
  k=1 约 61%，k=2 约 15%，k=3 约 7%。最大杂散约 `−6.02B + 3.92 dBc`（Nicholas–Samueli）。
- **LUT 最近邻，表深 N**（四分之一波表 `S = N/4`）：等效于相位量化到 `log2 N` 位，另加 16 位幅度舍入。
  象限折叠使 floor 方向在相邻象限翻转，均值偏置不能被常数相位完全吸收，所以
  `SQNR ≈ 37–43 dB`（N = 256），介于 `Δ²/3` 与 `Δ²/12` 之间。杂散型。
- **LUT 线性插值，N = 1024**：插值误差上界 `hb²/8 ≈ 4.7e−6`（约 −106 dB），被 16 位表项舍入盖过；
  如果相位字满 16 位，误差约在 16 位量化底（≈ −90 dB 以下），近似宽带。
- **CORDIC N 级**：残余角大致均匀分布在 `±atan(2^−(N−1))` → `SNR ≈ 4.77 + 6.02(N−1) dB`
  （N=11 约 65 dB，N=12 约 71 dB，N=16 约 95 dB，受 16 位输出限制实际约 90 dB）。残余角是角度的
  不规则分段函数，沿满熵 FCW 轨迹展开后谐波很多 → 宽带型。**这是本文最关键的建模假设，置信度中等**
  （A-假设 H_cordic_white）。

## 2. 现有 6 个 NCO 候选的诊断

| 候选 | 结构 | 有效相位 | 静态 SQNR（`cert_metrics`，16 位码全枚举） | 链上 NCO 误差（估算） | 谱型 |
|---|---|---|---|---|---|
| n1 | LUT256 nearest, B=12 | 8 位 | ≈ 37–43 | ≈ 同左 | 杂散 |
| n2 | LUT256 nearest, B=16 | 8 位 | 同 n1 | 与 n1 几乎逐位相同 | 杂散 |
| n3 | LUT1024 linear, B=12 | 12 位截断 | ≈ 90+ | ≈ −67（相位截断主导） | 杂散 |
| n4 | LUT1024 linear, B=16 | 16 位 | ≈ 90+ | ≈ −90 | 近宽带 |
| n5 | CORDIC12, B=12 | 12 位截断 | ≈ 71 | ≈ −65.5（截断 −67 ⊕ 残余 −71） | 杂散 + 宽带 |
| n6 | CORDIC16, B=16 | 16 位 | ≈ 88–92 | ≈ −90 | 宽带 |

（静态 SQNR 量级与旧结果一致，属于受污染的信息；表中其余列由第 1 节推出。）

三个结论：

1. **现有局部 SQNR 是稻草人。** `nco_static_metrics` 在 65536 个 16 位角度码上枚举，而参考值由截断后的
   码算出，所以**看不见相位截断**：n3 与 n4、n5 与「CORDIC12 满相位」的局部指标都相同。用这个指标构造
   出的 collapse / reversal（例如 n3 vs n4、n3 vs n6）只说明「局部指标定义错了接口」，审稿人会直接驳回。
   **公平的局部指标必须把累加器截断包含在 NCO 内**：参考相位取满精度累加器相位，在均匀相位上计算，
   即经典 DDS SNR 口径。这一条要写进 `M` 的定义（与 Codex 对齐）。
2. **n1 ≈ n2**：256 点表只用高 8 位相位，B=12 与 B=16 的差别只在折叠象限中低 4 位引起借位的约 1/32
   样点上，相差一个表项步长。二者成本也相同，不构成有意义的 pair。
3. **在公平指标下，现有池子里找不到反转。** 公平 SQNR 排序为
   n4 ≈ n6（≈90）> n3（≈67）> n5（≈65.5）> n1 ≈ n2（≈40）。其中唯一相近的是 n3 vs n5，但 n5 的误差等于
   **与 n3 完全相同的截断序列**（同 B、同 FCW）再加上独立的 CORDIC 残余，在任何契约下 n5 都不优于 n3。
   排序一致，没有 witness。

**预测 P0**：只用现有 6 个候选、公平局部指标 → Evaluation axis 结果为 **E0（在此池子内）**。
这不是核心失败，只说明候选池没有覆盖「杂散型 vs 宽带型、公平 SQNR 相近」这一关键区域，必须补候选。

## 3. 主预测 W1：跨结构的「杂散型 vs 宽带型」双契约互换

### 3.1 候选对

- **A = LUT1024 linear，相位截断 B = 12**（即现有 n3）：公平 SQNR ≈ 67.1 dB，误差几乎全是截断锯齿，
  最大杂散 ≈ −68 dBc，约占误差功率的 61%。
- **B = CORDIC_11，满 16 位相位**（新增候选）：公平 SQNR ≈ 65 dB（比 A 低约 2.2 dB），宽带型，
  最大杂散远低于 A（预估 ≤ −78 dBc）。

备选对（用于灵敏度检查，不另作 witness）：A' = LUT 线性 B=11（≈61 dB）vs B' = CORDIC_10 满相位
（≈59 dB）；以及 A vs CORDIC_12 满相位（≈71 dB，预测**无**反转，作负对照）。

### 3.2 两个契约（需 Codex 从真实规范冻结）

- **C1：灵敏度 / 无干扰，`ρ` = 栅格 mean**（吞吐型接收）；
- **C2：in-band / 窄带阻塞，`ρ` = 栅格 worst**（一致性测试：每个信道都必须通过）。

### 3.3 预测

| 契约 | 机制 | 预测排序 | 预估差距 |
|---|---|---|---|
| C1 | 无 blocker，NCO 误差只作用于期望信号；在 FCW 栅格上平均，杂散型的平均捕获比例 ≈ 白误差 | **A 优于 B** | ≈ 2.2 dB（等于 SQNR 差） |
| C2 | 强 blocker × NCO 杂散 → 被搬到 `b ± k·f_e`；栅格足够密时，总有某个信道把 k=1 谱线放进信号带 | **B 优于 A** | 见下 |

C2 差距估算（worst 信道，blocker 功率记 `P_b`）：

- A：`≈ P_b · 0.61 · σ_A²`（最坏时基频谱线整体落入信号带）；
- B：`≈ P_b · κ · σ_B²`，κ 为白误差捕获比例；
- 比值 `A/B = (0.61/κ) · 10^(−2.2/10)`：
  - 若 `q` 取符号域 EVM（κ ≈ 0.17）：约 2.2 倍，**A 差 ≈ 3.3 dB**；
  - 若 `q` 取整个输出带实现误差（κ ≈ 0.3）：约 1.2 倍，**A 差 ≈ 0.9 dB**，余量很薄，可能落在 `ε_Q` 以内。

**因此，`q` 取符号域实现 EVM²（与工程 EVM 语义一致）是 W1 成立的必要条件之一**，我建议 Codex 以它为主口径。

### 3.4 各局部指标的失败方向（mechanism witness）

- **SQNR**：A > B，与 C1 一致，与 C2 **strict reversal**；
- **SFDR**（工程上的标准 DDS 指标，必须放进 `M`，否则审稿人会说「你们为什么不用 SFDR」）：B > A，与 C2
  一致，与 C1 **strict reversal**；
- **WCE**：A 的最坏相位误差 `Δ` 固定，B 的最坏残余角约 `atan(2^−10)`，二者量级相近，预测为 **collapse**
  候选（依赖 `ε_m^(WCE)`）。

即：**没有一个局部标量指标能在两个真实契约下同时给出正确排序**。这就是 §2 命题需要的形态，
而且比「只有 SQNR 失败」更强。

### 3.5 decision witness

- 成本：LUT1024 线性（257 × 16 位表 + 1 个乘法器）vs CORDIC_11（11 级 × 3 个约 19 位的加减法器），
  面积量级相近但方向不确定，**需要综合**；
- 预测：在 C2 的硬门槛下，按 SQNR 选「达标且最省」会选中 A 或更窄截断的 LUT，而契约驱动会选 B 或
  更宽相位的 LUT（表长 ×4）。若 B 的面积 ≤ A 的面积 × 1.2，则局部选择被严格 Pareto 支配；
  否则只能用 regret 表述。**置信度：中低**（成本方向是最大未知数）。

### 3.6 落在哪个 E 分支

NCO 误差项在混频处严格线性，③（candidate-exact 复残差 + `D·H·diag(x)` 相干传播）应能完整复现 W1。
在 blocker 电平下，混频无饱和（`|x| ≤ 0.95`，表项已钳位到 32767），③ 与 ⑤ 的差只来自 CMUL / FIR
舍入，约 −90 dBFS 量级。**预测 W1 → E1（高置信度）**：这是已知的 DDS 杂散 / reciprocal mixing 物理，
论文不能把它当新误差理论，只能当「局部指标不保序且改变选择」的实证 + 契约搜索的动机。

### 3.7 使 W1 被证伪的条件

1. H_cordic_white 不成立：CORDIC 残余沿轨迹也形成少数强谱线（最大杂散 ≥ −72 dBc）→ C2 不反转；
2. 真实规范中的 blocker 电平太低（≤ +10 dB）→ C2 下 NCO 项被 CMUL / FIR 舍入淹没，差距 < `ε_Q`；
3. 冻结的真实信道栅格使 k=1 谱线在所有信道都落在带外 → C2 worst 不触发（必须用栅格细化 / held-out
   检查，不能事后挑点）；
4. 若 `q` 必须取整带实现误差，按 3.3 的估算 W1 可能落入 `ε_Q`。

## 4. 对照预测 W2：相位抖动（dither）

A = 截断 B 位，B = 同 B 位 + 相位抖动（LFSR + 加法器）。经典结论：抖动把杂散换成宽带底，总噪声约高
3 dB。预测与 W1 同向（C1 截断更好，C2 抖动更好），且 ② 层（Nicholas / Vankka 式 FCW-aware 预测）就能
解释。**作用是流水线的健全性检查**（结果必须与经典公式吻合），不作主 witness，因为它是单结构内的
已知技巧，不体现跨结构选择。

## 5. 低置信度假设 H-E2：高精度前沿上的舍入交叉项

仅作预注册假设，**不预先指定为 witness**（遵守 `PROPOSAL_v1.md` §5 纪律）。

- 场景：NCO 误差已接近 16 位底（n4 / n6 类，≈ −90 dBc），叠加强**单音**阻塞（例如 +40 dB），并使用截断型
  CMUL / FIR（c2、f6、f8）；
- 机制：blocker × NCO 是准周期信号，其舍入误差是（blocker 相位，NCO 相位）的确定性函数，会形成
  互调型谱线而不是白噪声；这类谱线的位置和幅度随 NCO 结构（LUT 表值 vs CORDIC 输出）改变，③ 不包含
  这一项；
- 量级：NCO × blocker ≈ −90 + 40 = −50 dB；混频 / FIR 舍入相对满幅约 −95 ~ −101 dBFS，相对期望信号
  （−40 dBFS）约 −55 ~ −61 dB，**同一量级**，所以在前沿顶端可能出现 ③ 失败、④ 才能解释的情形；
- 适用边界：只对单音 blocker 有意义；调制型干扰会把舍入误差白化，效应消失。需要 Codex 确认真实规范中
  是否有 CW / 窄带阻塞测试项，否则这条假设不能用（不得用人为场景撑 E2）。
- **预测：E2 的概率低（主观约 20–30%）**；更可能仍是 E1，此时论文的评价方法贡献不成立，应按
  E1 + S1 定位。

## 6. 需要与 Codex 对齐 / 由契约文档冻结的事项

1. `M` 的定义：SQNR 必须是**包含累加器截断**的公平口径；`M` 中加入 SFDR（定义在哪些测试 FCW 上）；
2. `q`：符号域实现 EVM²（推荐）还是整带实现误差；这直接决定 W1 的余量；
3. 信道栅格：真实 raster 映射到 `Fs_in = 2 MHz`、32 位累加器后，FCW 是否满熵（v1 教训：`1/16 MHz`
   的倍数会使相位截断轴完全失效）；
4. blocker：in-band / 窄带阻塞的电平（相对期望信号的 dB）、是否 CW、偏移频点；当前 `spec.py` 的 +6 dB
   远低于常见规范，W1 与 H-E2 都依赖更强的阻塞；
5. ADC 与缩放：强 blocker 下期望信号的 ADC 量化底属于场景（共同项），但要确认不会让 `q` 被 ADC 主导；
6. 成本口径：area 的综合流程与库，用于 3.5 的 decision witness。

## 7. 汇总

| 编号 | 内容 | 预测 | 置信度 |
|---|---|---|---|
| P0 | 现有 6 候选 + 公平局部指标 | 无保序失败（池子内 E0），需补候选 | 高 |
| W1 | LUT 截断 B=12 vs CORDIC_11 满相位，C1 mean-clean vs C2 worst-blocking | 双契约互换；SQNR、SFDR 各在一个契约下 strict reversal；E1 | mechanism 中高；decision 中低 |
| W2 | 截断 vs 抖动 | 同向，② 层可解释，E1；健全性检查 | 高 |
| H-E2 | 高精度 NCO + 强 CW blocker + 截断型 CMUL / FIR | 可能 ③ 失败、④ 解释；更可能仍 E1 | 低 |

**对论文的含义**：最可能的结果是 **E1**。DDC 这条链能给出干净的「局部指标不保序且改变选择」证据，
但评价方法的新意（E2）不太可能来自这里。论文主贡献更可能落在 E1 + S1：以契约驱动的跨结构联合搜索。
如果要争取 E2，需要到舍入 / 饱和真正起作用的链上去找（例如强阻塞下的 CIC / AGC，或 FFT 的级间缩放），
这应在迁移阶段（§4.4）有意识地选择。
