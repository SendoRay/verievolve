# 实验计划：固定预算下联合结构与定点化是否值得做

**问题**：在同一 DDC 数学语义、部署数值契约、候选语言与提案预算下，联合改变结构与定点参数能否改善实际硬件选择？
**方法命题**：用同一个强非 LLM 搜索引擎，比较允许结构—数值参数交错/联合修改与先选结构再锁定的决策方式；不把 GP 本身、typed IR 或 LLM 当作已证贡献。
**日期**：2026-10-01
**状态**：实验规格草案，待动作与统计口径独立审查后冻结；不是正式 S 实验的执行许可。C/D 已有结果，pilot、S、L 均未运行。

## 主张地图

| 待检验主张 | 为什么重要 | 最低可信证据 | 实验块 |
|---|---|---|---|
| C1：在所声明的有限语法/预算下，联合修改比提前锁结构找到更有工程价值的质量—面积点 | 区分设计决策收益与简单堆组件 | 同引擎、同初态、同评价和预算的多种子 joint/staged 比较；超过工程余量且 held-out 终考支持 | B1、B2 |
| C2：统一 IR 的质量—RTL—真实面积链路能支撑公平比较 | 只是 C1 的实现支撑，不单独声称新搜索算法 | 模型—RTL、身份、失败记账、FIR 掩码、非有限质量、真实完整 DDC 面积检查 | B0 |

必须排除的替代解释：我方空间更大、基线评价更弱、失败免费、预算不同、只挑成功种子、只赢一个弱锁图流程、仅一个轴的优化被包装成联合收益。

**不声称**：新误差理论、任意 RTL/无限递归发现、任意量化点移动、微结构/吞吐/PPA 联合优化、LLM 不可替代、击败所有通用 GP。当前为 E1；“同配置 GP 击败自己”不是可成立的命题。

## 论文实验故事

- 正文必须证明：公平比较资格；有限预算下可归因的 joint-vs-staged 收益；若成功，收益是否确实依赖两个轴。
- 附录支持：固定切片搜索正确性、失败分布、重复率、时间成本、历史留出/压力场景稳定性。

## 公共实验语言与动作规格

沿用现有 schema，不新增自由 RTL，也不把尚未实现的“任意插入/移动量化点”写进能力：

| 类别 | 允许的动作 | 定义边界 |
|---|---|---|
| 结构 | LUT/CORDIC 叶子互换；nearest/linear/quad 互换；根部构造/移除一层 phasor-compose；direct-symmetric/polyphase 互换 | 结构类和组合拓扑；所有系统共享同一构造器与默认初始化规则 |
| 数值参数 | LUT depth、CORDIC stages、phase_bits、compose split_bits/乘法舍入、FIR coefficient_bits/product_drop/accumulator_bits/rounding | 固定 primitive 类内的精度参数优化；基线不仅能调“字长”，还可调表深/级数，避免弱化 |
| 固定项 | ADC/输出格式、FCW 接口、抽取相位/率、初态、CMUL、固定 saturation 语义 | 不作为动作；不承诺未实现的任意边格式或饱和位置移动 |

范围严格来自当前 schema：depth∈{64,128,256,512,1024}，stages∈[7,20]，phase_bits∈[8,16]，split_bits∈[2,14]，FIR coefficient_bits∈[8,24]，product_drop∈[0,8]，accumulator_bits∈{0}∪[20,48]。低字长 mask 失败是部署失败，不通过缩池避开。

每次提案由 1 或 2 个原子动作构成，概率各 1/2；中间态不评价，只评价最终候选，一次提案计一次。joint 可混合结构/数值动作；staged 的阶段掩码是唯一被操纵变量。记录动作串和随机状态；越界/无效动作不免费重采样。所有 proposer 将来均调用同一 API，不允许 LLM 一次修改无限子树。

动作详规见 `PILOT_RULES_v1.md`：普通数值参数80%邻接/20%全域跳转，accumulator_bits哨兵域采用全域抽样，以免合法区域被饱和/掩码失败带隔断。构造默认值、路径解析、失败与抵消、族锁定/平局均在开跑前固定，不能随奖励调整。机器清单见 `PILOT_MANIFEST_v1.json`，当前禁止执行。

## 实验块

### B0：比较资格与小规模 pilot

- **主张/目的**：支持 C2，排除实现、反馈、预算和成本口径混杂。
- **数据**：冻结 36 main；开发测试只用合成输入；不访问 held-out/stress 数值。
- **系统**：共同 evaluator/动作/账本；joint 与 staged 的同一 GP 引擎。GP 使用 NSGA-II 式非支配排序+crowding、种群上限 8、二元 tournament；初始种群为已记录的同三份 fixture。
- **剩余前置项**：公共动作及失败计数测试；原语/参数边界的 bit-true/RTL 覆盖；搜索中饱和硬门槛的明确定义（推荐按实际接受输入/有效输出域且含前导，与 B/D 诊断一致，必须独立登记而非冒称继承旧计数）；严格的结果缓存身份与反馈隔离。
- **成本复用**：可以实现一个精确结果缓存，绑定 canonical IR、实际 RTL/工具/库/脚本及质量输入/版本；同一候选重复提案仍计预算。C/D 三份结果仅在全部身份核验后复用，所有臂相同初始缓存；不建设多级缓存平台。
- **pilot 预算草案**：3 个 seed={11,29,47}，2 臂，每臂 12 次提案（含 3 个初始点），共 72 次提案。只估计有效率、重复率、综合时延和运行方差，不作 S0/S1，不挑最好的 seed 或结构。
- **staged pilot**：前 6 次为结构阶段（含初始化），后 6 次锁定已选结构类/组合拓扑，仅调数值参数；锁定规则与正式规则相同。
- **成功条件**：身份/预算/动作检查全过，全部提案都有终态，能完成匹配预算；不能把面积或质量“赢了”当此块通过条件。
- **失败解释**：修实现或预算可执行性，不等于实证 S0。候选 timeout 是有成本的失败；全局工具/输入漂移是整次运行中止。
- **表图**：正文一张资格检查表；附录成本/失败表。
- **优先级**：MUST-RUN。

### B1：主检验——同引擎 joint vs 强 staged/WLO 与 cost-first

- **主张**：C1，只检验联合决策方式，不宣称新 GP 算法。
- **数据**：训练/选择只用 main；结束后将由 main 决定的候选集合固化，再作历史 held-out 终考。禁止在 held-out 重新挑选候选或改阈值。
- **比较系统（3 类基线以内）**：
  1. Joint GP：整个预算允许结构/数值混合动作。
  2. Staged GP / fixed-structure numeric tuning：同引擎同初态；前半预算探索结构，后半锁定结构类并优化表深/级数/位宽等。不能只给局部 kernel 指标——使用相同 full-chain q 和全链成本。
  3. Cost-first：同语言/同预算，父代/选择只按完整 DDC 面积，在整候选上检查共同质量；称成本优先对照，不冒称 Chassis 精确复现。强 beam 作为同语言联合参照，若未执行，不声称击败显式多路径强搜索器。
- **强锁图规则**：结构阶段末保留至多 3 个按 main `(Q,area)` rank/crowding 选出的结构族，预算在这些结构族轮转分配；不只锁定一个人为挑坏图。模板类为 leaf kind/interpolation、compose topology/child kinds、FIR kind；深度/级数/字长仍可调。结构阶段没有覆盖所有类别属于有限预算限制，需报告。
- **正式预算草案**：5 个独立配对 seed={101,211,307,401,503}；每臂 B∈{32,64}。选择规则在 pilot 前声明：pilot 完成且有效综合的 p90≤90秒则 B=64，否则 B=32。仅用成本决定 B，不读取谁赢来调预算；正式开始前再固化 manifest。
- **初始点与预算**：各臂相同 3 个 fixture，分别占用 3 次提案，即使缓存命中也不免费。失败、重复、语法/类型/mask/lowering/综合失败均计一次；内部子步骤不重复扣预算。
- **主统计（反方复核后的修订）**：分别做 joint–staged、joint–cost-first 两项B对B的配对seed HV比较，两项均须通过。staged与cost-first的union累计消耗2B，只作为更强辅助参照，不再把union叫作B预算算法。不得把不同seed的点合并成超级前沿再伪造重复统计。
- **HV 口径建议（审查后冻结）**：坐标 `(Q/q_budget, A/A_ref)`；A_ref 固定为 C/D 的首个 LUT+direct 候选 38346.294 µm²，不取各次结果 min/max。评价区域 `Q≤q_budget, A≤2*A_ref`，参考点 `(1,2)`；区域外点保留报告但不贡献 HV。
- **工程余量**：epsilon_Q保持原值。建议epsilon_A=383.46294 µm²（1% A_ref），仅在其余两固定候选补重复校准通过后生效；重复不一致则诊断，不扩大epsilon掩盖。观测差不是概率分布上界。最终规则在pilot前签定，不按搜索奖励调整。
- **置信区间建议**：两项B对B配对差分别做10000次bootstrap，PCG64 seed=271828，`numpy.quantile(method="linear")` 取2.5%/97.5%分位，两项下界均>0；报告所有seed差值，小样本不夸大精度。
- **工程点判据**：质量预算网格 `{0.25,0.5,1}×q_budget` 下有epsilon_A面积改善，或面积网格 `{0.5,0.75,1,1.25,1.5,2}×A_ref` 下有epsilon_Q质量改善。至少3/5seed满足；允许不同seed命中不同网格，但每个计入seed的同一格点须胜过两个B预算基线的有限最优值。空集HV=0、格点最优值/regret=null，不当作无限改善。
- **附带必报**：所有预算网格的 regret/覆盖、个别预算退化、可行率和失败成本。HV 改善不代表所有预算无损失。
- **成功条件**：工程点条件和两项B对B的HV条件同时满足才记S1。2B union另报，不冒充同预算主检验。资格完整且正式检验完成但不满足记S0；中断/预算未完成记inconclusive，不记S0。
- **失败解释**：相对于所测语言、契约和预算没有设计收益；停止 LLM 独特性与第二条链扩展，不改成功阈值。
- **表图**：主结果表、配对 seed HV/预算 regret 表及一张预算前沿图（真正绘图时遵循 dataviz 规范）。
- **优先级**：MUST-RUN。明确多路径 beam 的实现与范围是正式冻结前审查项，不能以“以后补”维持超范围主张。

### B2：条件性归因——是否真需要两个轴

- **主张/目的**：C1 的机制归因，排除“只优化一边也一样”。
- **触发**：B1 支持 S1 后才执行，避免无收益时继续扩实验。
- **比较**：同引擎同预算下 NCO-only（FIR 固定为初始参考）、FIR-only（NCO 固定为初始参考），加 joint。初始参考由上述既有首个候选定义，不按获胜设计反选。
- **指标**：同预算网格 regret、HV 和工程点覆盖；对获胜结构说明哪些动作共同变化，但不把事后解释当因果证据。
- **成功/失败**：若单轴已达到同等前沿，撤下“必须联合”的强主张，改为较窄的效率/决策结论；不伪造结构协同。
- **简洁性**：不增加代理模型/e-graph/诊断堆栈；无需与人为臃肿系统比较来证明简单。
- **表图**：正文紧凑消融表；案例放附录。
- **优先级**：条件 MUST-RUN。

### B3：仅 S1 后的 LLM 增量

- **当前地位**：不前置，不是当前方法必要组件。先不调用外部 LLM。
- **后续比较**：同语言/动作/预算下 GP 与 LLM × numerical/satisfaction，反馈量的交互检验；satisfaction 是同数值契约阈值化，不是 COEVO 复现。
- **必须防泄漏**：selection/archive/历史/特征/prompt 之前投影；不仅删输出字典 q。成本反馈共同开放；失败诊断层级也要相同。
- **失败解释**：L− 时 LLM 仅可替换 proposer，不强保独特性。
- **优先级**：S1 后另行冻结的条件实验；当前 CUT。

## 计算与数据预算

- GPU 小时：0；当前为本地 CPU bit-true 和 Yosys/ABC，不需 GPU 或外部模型 API。
- 已观察单次固定综合约57–237秒；不能把三个点的分布当完整搜索空间时延模型。每个候选仍以600秒上限执行并记录失败。
- pilot 建议全局墙钟上限 6 小时；若触顶，保存所有尝试并标 incomplete，只能调整资源/运行预算，不得作 S0/S1 或只比较完成更多的一臂。具体成本上限在启动前确认。
- 精确缓存是为避免相同候选重复综合，不返还提案预算。硬件成本 scope 不变；main/held-out 的质量缓存身份必须区分。
- 数据准备只使用既有冻结场景。main 用于开发；正式输出集合锁定后才读取历史 held-out；stress 仅外部稳健性，不并回主指标。
- 没有人工评价、没有新任务/新阈值搜索。最高风险是假设“锁结构确实有工程损失”；若强 staged/WLO 消除收益，应接受。

## 风险与防护

1. **比较命题漂移**：S 检验决策方式，不能声称联合 GP 击败同配置 GP；beam 若更好不否定联合决策，但否定 GP 算法优越性。
2. **合法空间与动作空间不同**：schema通过不等于action API已公平；动作大小、构造默认值、失败重采样必须先冻结和测覆盖。
3. **小样本/挑种子**：完整保留各seed数据；正式预算规则只看pilot成本，不看胜负；5seed CI仍报告限制。
4. **饱和域变化**：必须把实际接受输入/有效输出的统计域写入搜索专用契约，不复写旧 witness 的全输入时刻计数含义。
5. **面积文本精度 vs物理漂移**：stat的输出小数精度容差不等于epsilon_A；最终面积取JSON网表单元数×库面积。
6. **开发负结果被抹掉**：compose超预算10倍保留，不修改原fixture冒充成功；搜索后若出现新配置，用新结构hash记录。
